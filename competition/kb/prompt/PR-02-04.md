# PR-02-04 에이전트와 도구 연결
## 목표를 향해 움직이는 에이전트

에이전트는 사용자의 목표를 이해하고, 필요한 순서를 계획하며, 도구를 활용해 작업을 수행하는 시스템이에요. 예를 들어 회의록을 정리해 달라는 요청을 받으면 문서를 살펴보고, 주제를 나누고, 결과를 정리하는 순서를 생각할 수 있어요. 단순히 답변을 만드는 데서 나아가 실제 작업을 진행한다는 점이 특징이에요. 다만 계획이나 결과가 언제나 옳은 것은 아니므로 사용자가 살펴보아야 해요.

이 과정의 실습용 AI 어시스턴트 이름은 Helpy예요. Helpy에게 목표와 자료, 원하는 결과를 구체적으로 알려 주면 더 알맞은 계획을 세우는 데 도움이 돼요. 예를 들어 “정리해 줘”보다는 “회의록을 주제별로 나누고 각 주제의 핵심을 알려 줘”라고 요청해 보세요.

## API와 이음 규약

API는 서로 다른 프로그램이 정해진 방식으로 기능이나 데이터를 주고받는 창구예요. 식당에서 손님이 주문을 전달하고 음식을 받는 것처럼, 프로그램은 API에 필요한 일을 요청하고 결과를 받을 수 있어요. 서비스를 만드는 내부 방법을 모두 몰라도 정해진 요청 방식을 따르면 기능을 이용할 수 있어요.

이음 규약은 AI와 다양한 도구를 연결하기 위한 공통 규칙이에요. API를 이용하는 외부 서비스뿐 아니라 컴퓨터 안의 기능, 자료 저장소, 파일 접근 도구도 연결 대상이 될 수 있어요. 여러 도구를 비슷한 방식으로 다룰 수 있지만, 각 도구의 권한과 제공 기능까지 모두 같아지는 것은 아니에요.

연결을 돕는 서버는 서비스마다 따로 둘 수 있어요. Helpy 쪽의 연결 프로그램이 각 서버와 대화하고, 서버가 알맞은 도구나 API에 요청을 전달하는 방식이에요. 이렇게 나누면 필요한 서비스만 연결하거나 관리하기 쉬워요.

이 과정에서 이음 규약으로 연결한 외부 도구는 실행 전에 항상 사용자의 확인을 한 번 받아요. 확인할 때는 어떤 자료를 읽거나 바꾸는지, 어디로 보내는지 살펴보세요. 내용이 예상과 다르거나 권한이 지나치게 넓다면 실행을 거절하고 요청을 고쳐야 해요.

## 실습: 회의록 정리와 외부 저장소 연결

이번 실습에는 개인정보가 없는 가상의 회의록 열 개를 사용해요. 먼저 컴퓨터에 회의록을 정리할 프로젝트 폴더를 만들고 연습용 회의록을 넣어요. Helpy에서 이 폴더를 작업 대상으로 지정하고 “회의록을 읽고 주제별 분류 계획을 먼저 보여 줘”라고 요청해 보세요. 실제 메뉴나 연결 방법은 실습 환경의 안내를 따르세요.

이번 실습의 분류 주제는 행사, 학습, 환경, 기타예요. 어느 주제에도 확신이 없는 회의록은 기타로 분류해요. Helpy가 제안한 분류를 확인한 뒤 작업을 요청하고, 끝나면 각 회의록이 알맞은 곳에 있는지 직접 살펴보세요. 원본을 잃지 않도록 작업 전에는 별도 복사본을 보관해 두면 좋아요.

다음으로 이음 규약을 이용해 외부 온라인 저장소 도구를 연결해 보세요. 이번 실습에서는 정리한 회의록의 복사본만 외부 저장소에 올려요. 저장소에 연습용 폴더를 만들고 복사본을 올리는 작업을 각각 요청할 때, Helpy가 보여 주는 실행 내용과 대상을 확인한 후 승인해요. 연결이 준비되지 않았다면 교사의 안내를 받아 실습 환경을 확인해요.

업로드한 자료를 바탕으로 “행사 준비에 필요한 일을 모아 줘”라고 질문해 보세요. 외부 도구가 자료를 읽기 전에 요청 내용도 확인해요. 답변이 나오면 회의록 원문과 비교해 빠진 내용이나 잘못 묶인 내용이 없는지 점검해요. 복잡한 작업이나 기능 카드, 외부 도구를 많이 사용하면 토큰이 빠르게 소모될 수 있으니 실습 환경에서 사용량도 확인해요. 토큰은 AI가 글을 처리할 때 사용하는 작은 단위예요.

## 질문으로 확인해요

### Q. 에이전트는 답변만 만드는 프로그램과 어떻게 다른가요?
A. 목표를 이루기 위해 계획을 세우고 도구를 써서 실제 작업까지 수행할 수 있어요.

### Q. API와 이음 규약은 같은 건가요?
A. API는 프로그램 사이에서 기능과 데이터를 주고받는 창구이고, 이음 규약은 AI와 여러 도구를 연결하는 공통 규칙이에요.

### Q. 외부 도구가 연결되면 Helpy가 마음대로 실행하나요?
A. 아니요. 이 과정에서는 실행 전에 항상 사용자의 확인을 한 번 받아요.

### Q. 회의록의 주제가 불분명하면 어떻게 하나요?
A. 이번 실습에서는 기타로 분류하고, 결과를 확인할 때 다시 살펴봐요.

### Q. Helpy가 만든 요약은 그대로 믿어도 되나요?
A. 아니요. 원문과 비교해 빠진 내용이나 잘못된 내용이 없는지 확인해야 해요.
