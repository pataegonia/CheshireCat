# PR-03-02 코딩 에이전트 시작하기
## 코딩 에이전트와 함께 일하기

코딩 에이전트는 말로 받은 요청을 바탕으로 프로그램을 만드는 일을 돕는 도구예요. 이 과정의 코딩 에이전트 HelpyCode는 터미널에서 실행해요. 터미널은 글자로 명령을 입력하고 결과를 확인하는 창이에요. HelpyCode는 작업 중인 파일을 읽거나 수정하고, 오류를 고치거나 테스트를 만드는 일을 도울 수 있어요. 파일이 많은 프로젝트에서는 여러 파일의 맥락을 살펴 복잡한 작업을 나누어 처리할 수도 있어요.

그렇다고 결과를 무조건 믿으면 안 돼요. 요청과 다르게 파일을 바꾸거나 틀린 코드를 만들 수도 있기 때문이에요. 어떤 파일을 바꾸려는지 살펴보고 필요한 작업인지 확인해요. 완성된 코드도 직접 읽고 실행 결과를 검사하는 사람이 최종 책임자예요.

## 터미널과 입력창 구분하기

이번 과정에서는 빈 작업 폴더를 `연습장`이라고 정해요. 편집기에서 이 폴더를 열고 터미널을 켜요. 터미널이 `연습장`을 작업 폴더로 사용하도록 맞춘 뒤, `helpycode`를 입력해 HelpyCode를 시작해요. 처음에는 HelpyCode 입력창에 ‘안녕, 만나서 반가워!’라고 적어 대화해 보세요.

HelpyCode 입력창에는 자연어 지시문과 슬래시로 시작하는 명령을 모두 넣을 수 있어요. 자연어 지시문은 원하는 작업을 문장으로 설명하는 말이에요. 슬래시 명령은 HelpyCode의 기능을 정해진 방식으로 부르는 말이에요. 아래에서 첫째 줄은 일반 터미널에, 나머지 두 줄은 HelpyCode 입력창에 넣어요.

(표: PR-03-02-table1.csv)

이 과정에서는 모델 선택 연습에 `Helpy Pro`라는 모델을 사용해요. HelpyCode 입력창에 `/model`을 입력하고 나타나는 선택 화면에서 `Helpy Pro`를 골라요. 모델은 요청을 처리하는 방식에 영향을 주지만, 모델을 바꾸었다고 결과가 항상 정확해지는 것은 아니에요.

## 계산기 만들기 요청하기

이번 실습의 결과 파일 이름은 `계산기.py`예요. 계산기는 정수 두 개를 입력받아 덧셈과 뺄셈 결과를 차례로 보여 주기로 해요. 필요한 기능과 조건을 구체적으로 말하면 HelpyCode가 무엇을 만들어야 하는지 이해하기 쉬워요. 입력창에 다음과 같이 요청해 보세요.

‘외부 라이브러리 없이 파이썬으로 계산기.py를 만들어 주세요. 정수 두 개를 입력받아 덧셈과 뺄셈 결과를 차례로 출력해 주세요. 코드를 만든 뒤 실행 방법도 알려 주세요.’

HelpyCode가 파일 변경을 제안하면 내용을 확인한 뒤 진행해요. 코드는 조금 다르게 만들어질 수 있지만, 요청한 기능이 들어 있는지 살펴보세요. 다음은 가능한 코드의 한 예예요.

```python
첫째 = int(input("첫 번째 정수: "))
둘째 = int(input("두 번째 정수: "))
print("덧셈:", 첫째 + 둘째)
print("뺄셈:", 첫째 - 둘째)
```

`input`은 사용자가 입력한 값을 받고, `int`는 그 값을 정수로 바꿔요. 두 값을 더하거나 뺀 결과는 `print`로 보여 줘요. 이 간단한 예에서는 정수가 아닌 값을 넣었을 때의 오류 처리는 하지 않아요.

## 실행하고 확인하기

HelpyCode에서 안내한 방법으로 실행하거나, `/end`를 입력해 대화를 마친 뒤 일반 터미널에 `python 계산기.py`를 입력해 실행해요. 첫 번째 정수로 7, 두 번째 정수로 3을 입력했을 때의 결과는 다음과 같아요.

```text
첫 번째 정수: 7
두 번째 정수: 3
덧셈: 10
뺄셈: 4
```

입력한 순서대로 뺄셈이 이루어졌는지 확인해요. 다른 정수도 넣어 보고 예상과 다르면 코드와 요청을 다시 살펴보세요. 무엇이 잘못되었는지 HelpyCode에 설명하며 수정을 요청할 수도 있어요.
