# PR-03-03 AI로 데이터 분석하기
## 데이터로 질문하기
데이터는 관찰하거나 측정해 모은 사실, 수치, 기호 같은 원자료예요. 음원 차트의 순위와 곡의 특징도 데이터가 될 수 있어요. 여기에 질문과 맥락을 더해 분석하면 판단에 쓸 근거를 얻을 수 있어요. 예를 들어 “어떤 장르의 평균 에너지가 높을까?”라고 묻고 장르별 값을 비교할 수 있어요.

데이터 없이 직감만 따르면 반복되는 패턴을 놓치거나 문제의 원인을 잘못 짐작하기 쉬워요. 그렇다고 데이터가 결론을 자동으로 보장하지는 않아요. 자료가 어떻게 모였는지, 빠진 값은 없는지 살펴야 해요. 순위가 높은 곡의 에너지가 높더라도 에너지가 높은 순위를 만들었다고 단정할 수는 없어요.

## 분석 환경 고르기
Helpy에게 대화로 질문하면 개념을 빠르게 익히거나 분석 순서를 정하기 좋아요. 반면 HelpyCode는 터미널에서 실행하는 코딩 에이전트로, 허용된 파일을 읽고 코드를 작성해 실행한 뒤 결과를 확인하고 수정하는 과정을 반복할 수 있어요. 같은 분석을 다시 하거나 결과를 파일로 저장할 때 유용하지만, 실행 환경을 준비하고 오류를 확인해야 해요.

이번 실습의 자료는 가상의 음원 차트 자료인 차트자료.csv예요. 이 자료에는 곡 여덟 개의 순위, 장르, 에너지 값이 들어 있어요. 장르는 이 실습에서 만든 물결과 바람 두 종류이며 각각 곡 네 개씩이에요. 에너지는 곡의 활발한 정도를 나타내는 실습용 수치예요. 이 자료는 실제 청취자 전체를 대표하지 않으므로 분석 결과를 모든 음악에 적용하지 않아요.

## 터미널에서 준비하기
편집기에서 선생님이 준비한 자료 폴더를 열고 터미널을 띄워요. 이 과정에서는 터미널에 `HelpyCode`를 입력해 HelpyCode를 시작해요. 준비 과정에서 도움이 필요하면 선생님에게 물어봐요. 파일을 고치거나 명령을 실행하기 전에는 내용을 확인하고, 필요한 범위만 허용해요.

이 실습에서 HelpyCode를 사용하는 중 `!ls`를 입력하면 현재 폴더의 파일 목록을 확인해요. 앞의 `!`는 간단한 셸 명령을 실행하기 위한 접두사예요. 목록 확인을 긴 요청으로 설명하는 대신 명령으로 처리하면 시간과 토큰을 아낄 수 있어요. 목록에서 차트자료.csv가 보이는지 확인하고, 실습을 마칠 때는 HelpyCode에서 `/exit`를 입력해 종료해요.

## 두 가지 방법으로 분석하기
먼저 HelpyCode에 “현재 폴더의 차트 자료로 장르별 곡 수와 평균 에너지를 보여 주는 웹 대시보드를 만들어 줘”라고 요청해 봐요. 대시보드는 결과를 빠르게 볼 수 있어 성취감을 주지만, 규모가 커지면 오류 원인을 찾기 어렵고 만들어 둔 기능 밖의 질문에는 답하기 어려워요. 화면이 그럴듯해도 표시된 값이 원자료와 맞는지 확인해야 해요.

다음에는 단계별 스크립트로 분석해요. “자료의 열과 각 열의 의미를 소개해 줘”, “빠진 값과 중복을 확인하고 기초 통계량을 보여 줘”, “장르별 평균 에너지를 비교해 줘”라고 차례로 요청해요. 각 단계에서 코드와 출력이 질문에 맞는지 살펴보고 오류가 있으면 수정해요. 새로운 궁금증이 생기면 다음 단계에 반영할 수도 있어요.

이 과정의 데이터 분석 보고서는 ‘질문 → 데이터 → 결과 → 한계’ 네 부분으로 써요. 마지막으로 HelpyCode에 이 순서에 맞춘 마크다운 보고서를 요청해요. 결과에는 실제로 확인한 수치만 쓰고, 한계에는 적은 곡 수와 가상 자료라는 점을 밝혀요. AI가 작성한 설명도 원자료와 계산 결과를 대조해 검토해요.

### Q. 데이터는 이미 완성된 결론인가요?
A. 아니요. 데이터는 결론을 만들 때 쓰는 원자료예요. 무엇을 어떻게 모았는지 확인한 뒤 의미를 해석해야 해요.

### Q. 대시보드와 단계별 분석 중 무엇이 더 좋은가요?
A. 목적에 따라 달라요. 결과를 빨리 살펴보려면 대시보드가 편하고, 계산 과정과 오류를 자세히 확인하려면 단계별 분석이 유리해요.

### Q. 평균이 다르면 장르가 에너지 차이의 원인인가요?
A. 그렇게 단정할 수 없어요. 평균 차이는 관찰 결과일 뿐이며, 자료의 선정 방식이나 다른 요인도 살펴야 해요.

### Q. AI가 만든 그래프는 그대로 믿어도 되나요?
A. 아니요. 축의 이름과 단위, 빠진 값, 계산에 사용한 곡을 확인하고 원자료와 비교해야 해요.
