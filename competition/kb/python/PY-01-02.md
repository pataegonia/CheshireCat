# PY-01-02 출력·주석·입력
## 화면에 말하기

파이썬에서 화면에 글을 보여 주는 일을 출력이라고 해요. `print()`의 괄호 안에 출력할 내용을 넣으면 돼요. 글자는 따옴표로 감싸서 문자열로 표현해요. 큰따옴표와 작은따옴표를 모두 쓸 수 있지만, 문자열을 시작하고 끝내는 따옴표는 서로 같아야 해요.

꿈틀 중학교 코딩 동아리의 안내 캐릭터는 꿈틀 토끼예요. 출력 실습에서는 꿈틀 토끼에게 인사하고, 토끼가 하는 말을 화면에 보여 줄 거예요. 첫 번째 출력 문장은 `꿈틀 토끼, 안녕!`이에요. 두 번째 출력 문장은 `꿈틀 토끼가 "그럼 이제 '파이썬'을 배워 볼까?"라고 말했어요.`예요.

```python
# 실습 번호: 1 출력
print("꿈틀 토끼, 안녕!")
print("꿈틀 토끼가 \"그럼 이제 '파이썬'을 배워 볼까?\"라고 말했어요.")
```

실행 결과는 다음과 같아요.

```text
꿈틀 토끼, 안녕!
꿈틀 토끼가 "그럼 이제 '파이썬'을 배워 볼까?"라고 말했어요.
```

`print()`를 두 번 쓰면 기본적으로 두 줄에 나누어 출력돼요. 두 번째 코드에서 문자열 안의 큰따옴표 앞에 `\`를 붙였어요. 이렇게 하면 그 큰따옴표를 문자열의 끝이 아니라 출력할 글자로 나타낼 수 있어요. 반면 작은따옴표는 바깥쪽 큰따옴표와 종류가 달라서 그대로 넣었어요.

## 코드에 메모 남기기

`#`은 파이썬의 주석 기호예요. 코드에서 `#`으로 시작한 부분부터 그 줄의 끝까지는 파이썬이 실행하지 않아요. 주석을 쓰면 코드가 어떤 일을 하는지 메모할 수 있어요. 따옴표로 감싼 문자열 안의 `#`은 주석 기호가 아니라 출력할 글자라는 점도 기억해요.

이 과정의 코드 규칙에 따라 모든 실습 파일의 첫 줄에는 `# 실습 번호: 이름` 형식의 주석을 써요. 출력 실습의 첫 줄은 `# 실습 번호: 1 출력`이에요. 이 줄은 실습을 구분하는 메모이므로 실행 결과에는 나타나지 않아요. 주석을 지우거나 바꾸어도 보통 출력 내용은 달라지지 않지만, 실습 규칙에 맞게 첫 줄을 남겨 두어요.

## 이름을 입력받아 환영하기

이번에는 실행하는 사람이 입력한 이름으로 인사해 볼게요. `input()`은 입력한 내용을 문자열로 가져와요. `name = input()`이라고 쓰면 입력받은 문자열을 `name`이라는 변수에 저장해요. 변수는 값을 담아 두었다가 나중에 다시 꺼내 쓸 수 있는 이름이에요.

이 과정의 환영 실습에서는 `input()`의 괄호를 비워요. 괄호 안에 안내 문구를 넣으면 그 문구도 화면에 출력되므로, 정해진 결과와 달라질 수 있어요. 환영 실습의 첫 줄은 `# 실습 번호: 2 환영`이에요.

```python
# 실습 번호: 2 환영
name = input()
print(name + "님, 파이썬에 오신 것을 환영합니다!")
```

이 실습의 예시 입력 이름은 `새싹이`예요. 프로그램이 입력을 기다릴 때 다음을 입력하고 엔터를 눌러요.

```text
새싹이
```

예시 출력은 다음과 같아요.

```text
새싹이님, 파이썬에 오신 것을 환영합니다!
```

`+`는 여기에서 `name`에 저장된 문자열과 뒤의 문자열을 이어 붙여요. 다른 이름을 입력하면 그 이름으로 시작하는 환영 문장이 나와요. 입력을 화면에 표시하는 환경에서는 직접 입력한 글자가 출력 문장 위에 보일 수도 있어요. 출력이 예상과 다르면 따옴표의 짝과 괄호를 확인하고 다시 실행해 보세요.
