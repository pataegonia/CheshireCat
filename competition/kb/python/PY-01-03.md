# PY-01-03 변수와 연산
## 변수에 이름 붙이기

변수는 값을 저장하고 다시 꺼내 쓸 수 있도록 이름을 붙인 공간이에요. `apple = 6`은 변수 `apple`에 정수 6을 저장한다는 뜻이에요. 수학의 등호와 달리 `=`는 오른쪽의 값을 왼쪽 변수에 저장해요. 저장한 값은 나중에 다른 값으로 바꿀 수도 있어요.

이 과정의 변수 이름 규칙은 영어 소문자와 밑줄만 쓰고 세 글자 이상으로 짓는 것이에요. 단, 반복문에서 쓰는 `i`, `j`만 예외예요. `apple_count`는 규칙에 맞지만 `ab`, `apple2`, `Apple`은 맞지 않아요. 이 규칙은 파이썬 자체의 규칙보다 엄격해요. 파이썬에서는 숫자로 시작할 수 없고 띄어쓰기를 넣을 수 없지만, 이름 중간의 숫자나 대문자는 사용할 수 있어요. 대문자와 소문자도 서로 구분해요. 또한 `for`처럼 파이썬이 정해 둔 예약어는 변수 이름으로 쓸 수 없어요.

## 사칙연산으로 바구니 살펴보기

꿈틀 중학교 동아리의 사칙연산 실습에서는 사과 수를 6, 바구니 수를 2로 정해요. 이 실습에서는 합, 차, 곱, 나눈 값을 각각 `plus`, `minus`, `multi`, `div`에 저장해요. 각 변수는 계산 결과를 기억하므로 나중에 다시 출력하거나 계산에 이용할 수 있어요.

```python
apple = 6
basket = 2
plus = apple + basket
minus = apple - basket
multi = apple * basket
div = apple / basket
print('합은', plus)
print('차는', minus)
print('곱은', multi)
print('나눈 값은', div)
```

실행 결과:

```text
합은 8
차는 4
곱은 12
나눈 값은 3.0
```

`/`로 나누면 두 값이 정수이고 나누어떨어져도 결과는 실수인 `3.0`이에요. 실수는 소수점이 있는 수를 표현하는 자료형이에요. 계산 순서가 헷갈릴 때는 괄호를 써 보세요. 예를 들어 `(6 + 2) * 2`는 덧셈을 먼저 계산해요.

## 몫, 나머지와 거듭제곱

동아리의 다양한 연산 실습에서는 야구 점수판의 점수를 7, 묶음의 크기를 2로 정해요. 이 실습에서는 몫, 나머지, 거듭제곱 결과를 각각 `quoti`, `remain`, `square`에 저장해요.

(표: PY-01-03-table1.csv)

```python
score = 7
group = 2
quoti = score // group
remain = score % group
square = score ** group
print('몫은', quoti)
print('나머지는', remain)
print('제곱은', square)
```

실행 결과:

```text
몫은 3
나머지는 1
제곱은 49
```

7을 2씩 묶으면 세 묶음이 되고 1이 남아요. `//`는 음수의 경우에도 결과를 작은 정수 쪽으로 내림해요. `/`, `//`, `%`로 나눌 때 나누는 수가 0이면 오류가 나므로 주의해요.

## 입력값을 숫자로 바꾸기

`input()`으로 입력받은 값은 숫자처럼 보여도 문자열이에요. `int()`로 정수 형태의 문자열을 바꾸면 숫자로 계산할 수 있어요. 이 과정의 변환 실습에서는 입력 안내 문구 없이 `input()`의 괄호를 비워요. 첫째 입력값은 `first`, 둘째 입력값은 `second`에 정수로 저장해요. 이 실습에서 둘째 입력값은 0이 아닌 정수로 정해요.

```python
first = int(input())
second = int(input())
plus = first + second
multi = first * second
remain = first % second
print('합은', plus)
print('곱은', multi)
print('나머지는', remain)
```

입력 예시:

```text
5
3
```

실행 결과:

```text
합은 8
곱은 15
나머지는 2
```

예시에서 5와 3의 합은 8이고 곱은 15예요. 5를 3으로 나눈 나머지는 2예요. `int()`에 정수로 바꿀 수 없는 문자열을 넣으면 오류가 나요. 소수 형태의 문자열은 `float()`로 실수로 바꿀 수 있고, `str()`은 숫자를 문자열로 바꿀 때 사용할 수 있어요. 입력값의 자료형을 살펴보고 필요한 변환을 골라 보세요.
