# PY-01-04 문자열과 출력 형식
## 문자열을 이어 붙이고 반복해요

문자열은 따옴표로 감싼 글자의 모음이에요. `+`는 문자열을 이어 붙이고, `*`는 문자열을 정해진 횟수만큼 반복해요. 꿈틀 중학교 코딩 동아리의 실습 마스코트는 꿈틀이이고, 꿈틀이가 좋아하는 음식은 사과예요. 음식 이름을 다섯 번 외치고 글자 수도 확인해 볼게요.

```python
food = "사과"
repeat = food * 5
print("꿈틀이가 좋아하는 음식은 " + food + "예요!")
print(repeat)
print(len(repeat))
```

실행 결과:
```text
꿈틀이가 좋아하는 음식은 사과예요!
사과사과사과사과사과
10
```

`len()`은 문자열의 글자 수를 알려 줘요. 사과는 두 글자이므로 다섯 번 반복하면 열 글자예요. 다른 음식을 실험하고 싶다면 `food = input()`으로 바꿔 입력받을 수도 있어요. `input()`으로 받은 값은 문자열이에요.

## 인덱스로 글자를 꺼내요

인덱스는 문자열에서 글자의 위치를 나타내는 번호예요. 첫 글자의 인덱스는 0이고, `-1`은 마지막 글자를 가리켜요. 대괄호 안에 `시작:끝`을 쓰면 시작 위치부터 끝 위치 바로 앞까지 잘라 낼 수 있어요. 이를 슬라이싱이라고 해요.

과일 바구니 실습에서 바구니 이름은 `사과바구니`예요. 이름에서 첫 글자와 마지막 글자, 과일 이름을 꺼내 볼게요.

```python
basket = "사과바구니"
print(basket[0])
print(basket[-1])
print(basket[0:2])
```

실행 결과:
```text
사
니
사과
```

슬라이싱에서 끝 번호 2는 포함되지 않으므로 인덱스 0과 1의 글자만 나와요. 문자열에 없는 위치를 하나의 인덱스로 지정하면 오류가 나니 범위를 확인해요.

## 문자열을 메서드로 다듬어요

문자열 뒤에 점을 찍어 사용하는 기능을 문자열 메서드라고 해요. 동아리의 메시지 정리 실습에서는 양옆의 공백을 지우고, 영문을 소문자로 바꾼 다음 세미콜론을 공백으로 바꿔요. 정리할 메시지는 `I;LIKE;PYTHON`의 양옆에 공백을 붙인 문자열이에요.

```python
message = "  I;LIKE;PYTHON  "
first = message.strip()
second = first.lower()
final = second.replace(";", " ")
print(first)
print(second)
print(final)
print(final.find("python"))
```

실행 결과:
```text
I;LIKE;PYTHON
i;like;python
i like python
7
```

`strip()`은 양옆의 공백을 지우고, `lower()`는 영문을 소문자로 바꿔요. `replace()`는 지정한 부분을 바꾼 새 문자열을 만들어요. `find()`는 찾은 부분의 시작 인덱스를 돌려주며, 찾지 못하면 -1을 돌려줘요. 원래 문자열은 그대로이므로 결과를 변수에 저장해 사용해요.

## 바른말 필터를 만들어요

이 과정의 바른말 필터 예제는 금지어 목록 `bad_words`에 있는 단어를 `replace`로 같은 길이의 `*`로 바꿔요. 이 예제의 금지어 목록에는 `바보`와 `멍청이`가 들어 있어요.

```python
bad_words = ["바보", "멍청이"]
text = "바보 대신 응원해요"
for word in bad_words:
    text = text.replace(word, "*" * len(word))
print(text)
```

실행 결과:
```text
** 대신 응원해요
```

반복문이 목록의 단어를 하나씩 확인해요. `len(word)`만큼 별표를 반복하므로 바뀐 단어와 별표의 길이가 같아요. 목록에 없거나 문장이 달라진 표현까지 찾아내는 필터는 아니에요.

## 출력 모양을 정해요

`print()`의 `sep`은 여러 값 사이에 넣을 문자열이고, `end`는 출력 끝에 붙일 문자열이에요. 기본값은 각각 공백과 줄바꿈이에요. 동아리 출발 구호는 `꿈틀`과 `동아리`를 빗금으로 구분하고 느낌표 뒤에 `출발`을 이어 써요.

```python
print("꿈틀", "동아리", sep=" / ", end="!")
print("출발")
```

실행 결과:
```text
꿈틀 / 동아리!출발
```

이 과정에서는 출력 형식을 맞출 때 f-string만 쓰고 % 포매팅과 `format()`은 쓰지 않아요. f-string은 따옴표 앞에 `f`를 붙이고 중괄호 안에 값이나 변수를 넣어요. 성적표 실습의 점수는 87.456점이며 화면에는 소수 둘째 자리까지 표시해요.

```python
score = 87.456
print(f"성적표 점수: {score:.2f}점")
```

실행 결과:
```text
성적표 점수: 87.46점
```

`:.2f`는 숫자를 소수 둘째 자리까지 표시하도록 정해요. 출력할 때 반올림되어 보이지만 변수에 저장된 원래 점수는 바뀌지 않아요.
