# PY-02-01 비교·논리 연산과 if 조건문
## 비교 연산자로 조건 만들기

꿈틀 중학교 코딩 동아리에서는 조건을 만족하는지 살펴보고 서로 다른 동작을 실행해요. 비교 연산자는 두 값을 비교해 참이면 `True`, 거짓이면 `False`를 만들어요.

(표: PY-02-01-table1.csv)

값을 저장하는 `=`와 같은지 비교하는 `==`를 구별해요. 예를 들어 `a = 5`는 5를 저장하고, `a == 5`는 저장된 값이 5인지 비교해요.

## 논리 연산자로 조건 묶기

`and`는 연결된 조건이 모두 참일 때 참이에요. `or`는 하나 이상 참이면 참이고, `not`은 참과 거짓을 뒤집어요. 괄호로 비교식을 묶으면 읽기 쉬워요.

동아리의 과일 바구니 예제에는 사과 4개와 배 2개가 있어요. 이 예제에서 나눔 준비 완료 조건은 사과가 3개 이상이고 배가 2개 이상인 것이에요.

```python
apple = 4
pear = 2
print((apple >= 3) and (pear >= 2))
print((apple < 3) or (pear >= 2))
print(not (apple >= 3))
```

실행 결과:

```text
True
True
False
```

첫 줄은 두 조건이 모두 참이에요. 둘째 줄은 사과 조건이 거짓이어도 배 조건이 참이라서 참이에요. 셋째 줄은 참을 뒤집어 거짓이 돼요.

## if-else와 들여쓰기

`if` 뒤의 조건이 참이면 그 아래 코드를 실행해요. 거짓이면 `else` 아래 코드를 실행해요. 조건과 `else` 뒤에는 콜론 `:`을 붙이고, 실행할 코드는 보통 공백 네 칸으로 들여써요. 같은 블록의 줄은 들여쓰기 깊이를 맞춰요.

동아리 숫자 맞히기 예제의 정답은 25예요. `input()`으로 입력받은 글자를 `int()`로 정수로 바꾼 뒤 비교해요. 입력 안내 문구는 넣지 않아요.

```python
answer = 25
num = int(input())

if num == answer:
    print('정답입니다!')
else:
    print('정답 숫자와 다릅니다.')
print('비교를 마쳤어요.')
```

입력으로 `30`을 넣었을 때 실행 결과예요.

```text
정답 숫자와 다릅니다.
비교를 마쳤어요.
```

마지막 `print`는 들여쓰지 않았으므로 조건문 밖에 있어요. 정답 여부와 관계없이 실행돼요. 입력이 `25`라면 첫 줄에 `정답입니다!`가 출력돼요.

## if-elif-else로 여러 경우 나누기

`elif`는 앞의 조건이 거짓일 때 다른 조건을 검사해요. 위에서부터 검사하다가 처음으로 참인 가지 하나만 실행해요. 모두 거짓이면 `else`를 실행해요. 같은 숫자 맞히기에서 큰지 작은지도 알려 줄 수 있어요.

```python
answer = 25
num = int(input())

if num > answer:
    print('입력받은 숫자가 더 큽니다.')
elif num < answer:
    print('입력받은 숫자가 더 작습니다.')
else:
    print('정답입니다!')
```

입력으로 `10`을 넣었을 때 실행 결과예요.

```text
입력받은 숫자가 더 작습니다.
```

`30`을 넣으면 더 크다는 문장이, `25`를 넣으면 정답이라는 문장이 출력돼요. 세 경우 중 하나만 실행되는지 확인해 보세요.

## 성적표에 조건문 적용하기

이 과정의 학점 예제는 점수를 0점부터 100점까지로 정해요. 90점 이상은 A, 80점 이상은 B, 70점 이상은 C, 그 밖은 F예요. 학점은 네 단계뿐이며 D 학점은 없어요.

```python
score = 85

if score >= 90:
    print('A')
elif score >= 80:
    print('B')
elif score >= 70:
    print('C')
else:
    print('F')
```

실행 결과:

```text
B
```

85는 90 이상이 아니지만 80 이상이므로 B가 나와요. 높은 기준부터 검사해야 95점이 먼저 B 조건에 걸리는 일을 막을 수 있어요.
