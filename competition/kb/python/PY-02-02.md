# PY-02-02 조건문 안의 조건문과 리스트 조건
## 조건문 안에 조건문 넣기

조건에 따라 다른 조건을 다시 확인해야 할 때가 있어요. 이때 `if`나 `else`의 실행 부분에 또 다른 조건문을 넣으면 중첩 조건문이 돼요. 안쪽 조건문은 바깥쪽 조건문이 해당 실행 부분을 선택했을 때만 검사해요.

꿈틀 중학교 코딩 동아리의 숫자 맞히기 실습에서 정답은 25예요. 입력한 수가 정답보다 큰지 먼저 확인하고, 크지 않다면 안쪽에서 작은지 확인해요.

```python
answer = 25
num = int(input())

if num > answer:
    print("입력받은 숫자가 더 큽니다.")
else:
    if num < answer:
        print("입력받은 숫자가 더 작습니다.")
    else:
        print("정답입니다!")
```

입력으로 `30`을 넣었을 때 실행 결과는 다음과 같아요.

```text
입력받은 숫자가 더 큽니다.
```

`10`을 넣으면 바깥쪽 `else`로 들어가 안쪽 `if`가 참이 되므로 더 작다는 문장이 나와요. `25`를 넣으면 두 비교가 모두 거짓이어서 안쪽 `else`가 실행돼요. `input()`은 입력을 문자열로 받으므로 수의 크기를 비교하려고 `int()`로 정수로 바꿨어요.

들여쓰기는 코드의 소속을 나타내요. 위 코드에서 안쪽 `if`와 안쪽 `else`는 같은 깊이에 있고, 둘 다 바깥쪽 `else`에 속해요. 들여쓰기를 일정하게 맞춰야 원하는 순서로 검사할 수 있어요.

이 과정에서는 조건문을 세 겹보다 깊게 겹쳐 쓰지 않고, 그럴 때는 `and`나 `or`로 조건을 합쳐요. 두 조건이 모두 필요하면 `and`를, 적어도 하나가 필요하면 `or`를 써요. 예를 들어 `num > 0 and num < 30`은 수가 0보다 크고 30보다 작은지 한 번에 확인해요. 조건을 합칠 때는 원래 조건과 같은 뜻인지 살펴봐요.

## in으로 리스트 확인하기

동아리의 숫자 카드 실습에서 확인할 카드 목록은 `[3, 7, 12, 18, 24]`예요. `값 in 리스트`는 그 값이 리스트에 있으면 참, 없으면 거짓이 돼요. 숫자 카드 `12`는 목록에 있고 `6`은 없어요.

```python
cards = [3, 7, 12, 18, 24]
num = int(input())

if num in cards:
    print("목록에 있는 카드입니다.")
else:
    print("목록에 없는 카드입니다.")
```

입력으로 `12`를 넣었을 때 실행 결과예요.

```text
목록에 있는 카드입니다.
```

여기서 `int()`를 빼면 입력값은 문자열이므로 정수 `12`가 들어 있는 리스트에서 같은 값으로 찾을 수 없어요. 리스트의 값과 비교할 값의 자료형을 맞추는 것이 중요해요.

## 리스트의 개수로 조건 정하기

동아리의 색 공 주머니 실습에는 빨강 공 18개, 파랑 공 20개, 노랑 공 12개가 있어요. 공은 모두 50개이며, 입력한 색의 공이 20개 이상인지 확인해요. 리스트의 `count(값)`은 그 값과 같은 요소가 몇 개인지 돌려줘요.

```python
color = ["red"] * 18 + ["blue"] * 20 + ["yellow"] * 12
ball = input()

if color.count(ball) >= 20:
    print("이 색의 공은 20개 이상 담겨 있습니다.")
else:
    print("이 색의 공은 20개보다 적게 담겨 있습니다.")
```

입력으로 `blue`를 넣었을 때 실행 결과예요.

```text
이 색의 공은 20개 이상 담겨 있습니다.
```

`["blue"] * 20`은 파랑을 나타내는 문자열이 20개인 리스트를 만들고, `+`는 각 리스트를 이어 붙여요. `>= 20`은 20도 포함하므로 파랑 공이 정확히 20개여도 첫 번째 문장이 나와요. `red`를 넣으면 18개이므로 두 번째 문장이 나와요. 없는 색을 입력하면 `count`의 결과는 0이에요.
