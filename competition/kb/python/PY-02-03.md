# PY-02-03 for 반복문과 range
## range로 반복할 숫자 정하기

`for` 반복문은 정해진 순서대로 값을 하나씩 꺼내 같은 작업을 반복해요. `range(시작, 끝, 간격)`은 시작부터 간격만큼 변하는 정수를 만들되, 끝은 포함하지 않아요. 간격을 생략하면 1이고, `range(끝)`처럼 끝만 쓰면 0부터 시작해요. 간격에 0은 쓸 수 없어요.

꿈틀 중학교 동아리의 박수 게임에서는 3부터 30 이전까지 3의 배수마다 박수를 쳐요. 게임에 나온 숫자를 모두 출력한 뒤에는 ‘박수 완료’라고 알려요.

```python
for number in range(3, 30, 3):
    print(number)
print('박수 완료')
```

실행 결과는 다음과 같아요.

```text
3
6
9
12
15
18
21
24
27
박수 완료
```

여기서 `number`는 반복할 때마다 다음 숫자를 받아요. 30은 끝값이므로 출력되지 않아요. 마지막 `print`는 반복문 바깥에 있어서 한 번만 실행돼요.

## 음수 간격으로 거꾸로 세기

간격이 음수이면 숫자가 작아지는 방향으로 진행해요. 꿈틀 중학교 야구 점수판의 거꾸로 세기 연습은 10에서 시작해 4씩 빼고, -10 이전에서 멈춰요.

```python
for number in range(10, -10, -4):
    print(number)
```

실행 결과예요.

```text
10
6
2
-2
-6
```

끝값 -10은 포함되지 않아요. 시작에서 끝 쪽으로 갈 수 있도록 간격의 방향을 정해야 해요. 예를 들어 시작이 끝보다 작은데 간격이 음수이면 꺼낼 숫자가 없어 반복문 본문이 실행되지 않아요.

## 이중 for로 모양 그리기

반복문 안에 다른 반복문을 넣으면 이중 for 반복문이에요. 바깥쪽이 한 번 반복될 때마다 안쪽 반복문은 자신의 범위를 처음부터 끝까지 돌아요.

이 과정의 삼각형과 다이아몬드 모양 그리기 예제에서는 `*` 대신 `#` 기호를 써요. 동아리의 계단 실습에서는 맨 위를 1단으로 세고, 각 단에 단수만큼 `#`을 놓아요. 이번에는 단 수로 3을 입력해 보아요.

```python
stair = int(input())
for level in range(1, stair + 1):
    for 칸 in range(level):
        print('#', end='')
    print()
```

입력은 다음과 같아요.

```text
3
```

실행 결과예요.

```text
#
##
###
```

`input()`으로 받은 글자를 `int()`로 정수로 바꾸어요. 바깥쪽의 `level`은 1부터 3까지 바뀌고, 안쪽 반복문은 그 단수만큼 기호를 출력해요. `end=''`는 기호마다 줄을 바꾸지 않게 해요. 안쪽 반복이 끝난 뒤의 `print()`가 다음 단을 위해 줄을 바꾸어요.

## 반복문의 else로 끝까지 확인하기

반복문의 `else`는 반복이 `break` 없이 정상적으로 끝나면 실행돼요. 처음부터 반복할 항목이 없어도 정상 종료이므로 실행돼요. 반대로 `break`로 해당 반복문을 빠져나오면 그 반복문의 `else`는 건너뛰어요.

동아리 과일 바구니 확인 실습에는 사과, 배, 귤이 들어 있고 찾을 과일은 복숭아예요. 발견하면 반복을 멈추고, 끝까지 찾지 못하면 알려요.

```python
for fruit in ['사과', '배', '귤']:
    if fruit == '복숭아':
        print('복숭아 발견')
        break
else:
    print('복숭아가 없어요')
```

실행 결과예요.

```text
복숭아가 없어요
```

복숭아가 없어 `break`를 만나지 않았으므로 `else`가 실행돼요. 만약 목록에 복숭아가 있다면 발견을 출력한 뒤 `break`로 나가므로 `else`는 실행되지 않아요. `while` 반복문도 조건이 거짓이 되어 정상 종료하면 `else`를 실행하고, `break`로 종료하면 실행하지 않아요.
