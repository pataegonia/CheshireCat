# PY-02-04 while 반복문과 break·continue·pass
## 조건이 참인 동안 반복하기

`while` 반복문은 조건이 참인 동안 들여쓰기한 본문을 반복해요. 조건이 거짓이면 반복문을 벗어나 다음 코드로 이동해요. 반복할 때 조건에 쓰는 값을 바꾸지 않으면 원하지 않게 계속 반복할 수 있으니 주의해요.

꿈틀 중학교 코딩 동아리의 ‘별 계단’ 실습에서는 만들 단의 수를 양의 정수로 입력해요. 맨 위의 첫 단에는 별표를 한 개 찍고, 아래 단으로 갈 때마다 별표를 한 개씩 늘려요. 이 실습에서는 입력을 받을 때 괄호 안을 비운 `input()`을 사용해요.

```python
stair = int(input())
n = 1
while n <= stair:
    print('*' * n)
    n += 1
```

입력 예시:

```text
3
```

실행 결과:

```text
*
**
***
```

`n`은 현재 출력할 단의 번호예요. 입력이 3이면 1단부터 3단까지 출력한 뒤 `n`이 4가 되므로 조건이 거짓이 되어 멈춰요. `n += 1`을 빼면 `n`이 그대로여서 반복이 끝나지 않아요.

## 항상 참인 조건과 break

`while True`는 조건이 항상 참이라서 본문에서 따로 끝내지 않으면 계속 반복해요. `break`는 가장 가까운 반복문을 즉시 끝내요. 이 과정에서 `while True`를 쓸 때는 끝내는 `break` 조건을 반복문 본문의 첫 줄에 둬요.

동아리의 ‘점수 모으기’ 실습에서는 양의 정수를 차례로 입력하고, 마지막에 0을 입력해 게임을 끝내요. 출력할 값은 0이 나오기 전까지 입력한 점수의 합이에요. 몇 개를 입력할지 미리 몰라도 반복문으로 처리할 수 있어요.

```python
total = 0
num = int(input())
while True:
    if num == 0: break
    total += num
    num = int(input())
print(total)
```

입력 예시:

```text
1
4
2
0
```

실행 결과:

```text
7
```

반복문에 들어가기 전에 첫 점수를 읽어요. 0이 아니면 합에 더하고 다음 점수를 읽은 뒤, 다시 첫 줄에서 종료 조건을 확인해요. 처음부터 0을 입력하면 더할 점수가 없으므로 0을 출력해요.

## continue와 pass 비교하기

`continue`는 현재 차례의 남은 코드를 건너뛰고 다음 반복으로 넘어가요. `pass`는 아무 동작도 하지 않는 자리 표시예요. 반복을 끝내거나 다음 차례로 바로 넘어가지 않아요. 동아리의 비교 실습에서는 0부터 시작해 숫자 1에서 각 명령을 시험하고, `break` 실습은 2에서 멈춰요.

```python
n = 0
while n < 5:
    if n == 1:
        pass
    print(n)
    n += 1

n = 0
while n < 5:
    n += 1
    if n == 2:
        continue
    print(n - 1)

n = 0
while n < 5:
    if n == 2:
        break
    print(n)
    n += 1
```

실행 결과:

```text
0
1
2
3
4
0
2
3
4
0
1
```

첫 반복문은 `pass` 뒤의 출력도 실행해요. 둘째 반복문은 출력할 값이 1인 차례를 건너뛰어요. 이때 `continue` 전에 `n`을 늘려야 같은 값에 머물지 않아요. 셋째 반복문은 2를 출력하기 전에 끝나요.

## 질문으로 확인하기

### Q. while 조건은 언제 확인해요?
A. 본문을 실행하기 전마다 확인해요. 처음부터 거짓이면 본문을 한 번도 실행하지 않아요.

### Q. break는 프로그램 전체를 끝내나요?
A. 아니요. 가장 가까운 반복문을 끝내고 그 뒤의 코드로 이동해요.

### Q. continue를 만나면 조건도 건너뛰나요?
A. 아니요. 현재 차례의 남은 본문을 건너뛴 뒤 반복 조건을 다시 확인해요.

### Q. pass를 쓰면 반복이 멈추나요?
A. 아니요. 아무 동작 없이 다음 문장으로 진행해요.

### Q. 점수 모으기에서 첫 입력을 반복문 앞에 두는 이유는 무엇인가요?
A. 반복문 본문의 첫 줄에서 입력값이 0인지 바로 검사하기 위해서예요.
