# PY-03-01 리스트 만들기와 활용하기
## 리스트로 과일 담기

리스트는 여러 값을 순서대로 묶어 저장하는 자료형이에요. 대괄호 안에 값을 쉼표로 구분해 넣으며, 빈 리스트는 `[]`로 만들어요. 문자열과 숫자처럼 서로 다른 종류의 값도 한 리스트에 담을 수 있어요.

이 과정의 과일 바구니 예제에서는 리스트 이름을 `fruit_basket`으로 쓰고, 바구니에는 과일을 최대 7개까지만 담아요. 이 제한은 동아리 실습 규칙일 뿐, 파이썬이 자동으로 검사하지는 않아요. 과일을 추가하기 전에 `len(fruit_basket)`으로 개수를 확인해요.

동아리의 첫 바구니에는 사과, 배, 포도를 이 순서로 담아요. 첫 과일은 사과이고, 마지막 과일은 포도예요. 아래 코드를 실행해 순서와 위치를 확인해 보세요.

```python
fruit_basket = ['사과', '배', '포도']
print(fruit_basket)
print(fruit_basket[0])
print(fruit_basket[-1])
print(fruit_basket[0:2])
```

실행 결과:
```text
['사과', '배', '포도']
사과
포도
['사과', '배']
```

## 인덱싱과 슬라이싱

리스트에서 값 하나를 위치로 꺼내는 것을 인덱싱이라고 해요. 위치를 나타내는 인덱스는 0부터 시작해요. `-1`은 마지막 위치이고, 존재하지 않는 위치를 인덱싱하면 오류가 나요.

`[시작:끝]`처럼 범위를 지정해 새 리스트를 얻는 것을 슬라이싱이라고 해요. 시작 위치의 값은 포함하지만 끝 위치의 값은 포함하지 않아요. 따라서 위의 `[0:2]`는 인덱스 0과 1의 값을 담아요. 시작이나 끝을 생략하면 각각 처음이나 끝까지 사용해요. 슬라이싱만으로 원래 리스트가 바뀌지는 않아요.

## 리스트에 넣고 빼기

리스트 메서드는 리스트에 점을 붙여 사용하는 기능이에요. 동아리 실습에서는 첫 바구니에 자두를 끝에 추가하고, 귤을 인덱스 1에 끼워 넣은 다음, 배를 제거해요.

(표: PY-03-01-table1.csv)

다음 코드는 앞에서 만든 `fruit_basket`에 이어서 실행해요. 추가하기 전마다 바구니에 자리가 있는지 확인해요.

```python
if len(fruit_basket) < 7:
    fruit_basket.append('자두')
if len(fruit_basket) < 7:
    fruit_basket.insert(1, '귤')
fruit_basket.remove('배')
print(fruit_basket)
```

실행 결과:
```text
['사과', '귤', '포도', '자두']
```

`remove`에 없는 값을 주면 오류가 나요. 반면 `pop()`은 값이 아니라 위치를 기준으로 지우며, 괄호를 비우면 마지막 값을 꺼내요. `sort()`는 원래 리스트 자체를 바꾸므로 정렬 전 순서가 필요하다면 미리 따로 보관해요.

## 문자열을 나누고 반복하기

문자열의 `split()`을 사용하면 공백을 기준으로 문자열을 나누어 리스트를 만들 수 있어요. 동아리의 글자 실습에서는 입력받은 문자열을 `word`에, 나눈 결과를 `words`에 저장해요. 또 `words`를 세 번 이어 붙인 리스트를 `repeat`에 저장해요. `input()`의 괄호는 비워 두어요.

```python
word = input()
words = word.split()
repeat = words * 3
print(words)
print(repeat)
print(len(repeat))
```

입력 예시:
```text
꿈 틀
```

실행 결과:
```text
['꿈', '틀']
['꿈', '틀', '꿈', '틀', '꿈', '틀']
6
```

`* 3`은 각 글자를 세 번 늘리는 것이 아니라 리스트 전체를 세 번 이어 붙여요. `len()`은 완성된 리스트의 요소 개수를 알려 줘요.

## 숫자 리스트 활용하기

동아리 점수판 실습의 `num_list`에는 처음에 3, 1, 2, 5, 6, 4가 이 순서로 들어 있어요. 최댓값을 먼저 구한 뒤 인덱스 2에 0을 넣고, 마지막 값을 삭제하고, 오름차순으로 정렬해요.

```python
num_list = [3, 1, 2, 5, 6, 4]
number = max(num_list)
print('최댓값:', number)
num_list.insert(2, 0)
print('0 삽입:', num_list)
num_list.pop()
print('마지막 값 삭제:', num_list)
num_list.sort()
print('정렬:', num_list)
```

실행 결과:
```text
최댓값: 6
0 삽입: [3, 1, 0, 2, 5, 6, 4]
마지막 값 삭제: [3, 1, 0, 2, 5, 6]
정렬: [0, 1, 2, 3, 5, 6]
```

`max()`는 리스트에서 가장 큰 값을 돌려줘요. 이 실습에서는 리스트를 바꾸기 전에 최댓값을 `number`에 저장했어요. 각 단계의 출력 결과를 비교하며 리스트의 순서가 어떻게 달라지는지 살펴보세요.
