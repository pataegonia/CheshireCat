# PY-03-02 튜플·집합·딕셔너리
## 자료를 담는 네 가지 방법

꿈틀 중학교 코딩 동아리는 자료의 성격에 따라 알맞은 자료구조를 골라요. 순서가 중요한지, 내용을 바꿀 수 있는지, 중복을 허용하는지 살펴보면 선택하기 쉬워요.

(표: PY-03-02-table1.csv)

딕셔너리는 위치보다 이름표인 키로 값을 찾는 데 편리해요. 파이썬 딕셔너리는 입력 순서를 유지하지만, 이 과정에서는 순서가 아닌 키를 이용해 값을 찾아요. 이 과정에서 딕셔너리의 키는 항상 문자열로 쓰고, 값을 꺼낼 때는 대괄호 대신 `get()`을 써요.

## 바뀌지 않는 순서, 튜플

튜플은 쉼표로 요소를 구분하며 보통 괄호로 감싸요. 동아리 행사에서 과일을 소개하는 순서는 사과, 배, 귤로 정했어요. 순서를 그대로 보관할 때 튜플이 어울려요. 요소가 하나뿐인 튜플은 `('사과',)`처럼 쉼표가 꼭 필요해요.

```python
fruit_order = ('사과', '배', '귤')
print(fruit_order[0])
print(sorted(fruit_order))
print(list(fruit_order))
```

실행 결과는 다음과 같아요.

```text
사과
['귤', '배', '사과']
['사과', '배', '귤']
```

`sorted()`는 정렬된 새 리스트를 만들고 원래 튜플은 바꾸지 않아요. `list()`로 리스트를 만들면 그 리스트의 요소는 바꿀 수 있어요. 튜플 자체에는 리스트처럼 요소를 추가하거나 삭제할 수 없어요.

## 중복 없이 모으는 집합

동아리의 첫째 과일 바구니에는 사과와 배가 있고, 둘째 바구니에는 배와 귤이 있어요. 집합으로 담으면 공통 과일이나 두 바구니에 있는 모든 과일을 쉽게 찾을 수 있어요. 집합에 같은 요소를 여러 번 넣어도 하나만 남아요.

```python
first = {'사과', '배', '사과'}
second = {'배', '귤'}
print(sorted(first & second))
print(sorted(first | second))
print(sorted(first - second))
print({'배'}.issubset(first))
```

실행 결과예요.

```text
['배']
['귤', '배', '사과']
['사과']
True
```

`&`는 두 집합에 공통으로 있는 교집합이며 `intersection()`과 같아요. `|`는 모두 모은 합집합으로 `union()`과 같아요. `-`는 앞 집합에서 뒤 집합의 요소를 뺀 차집합이며 `difference()`와 같아요. `issubset()`은 앞의 집합이 괄호 안 집합의 부분집합인지 확인해요. 집합 자체의 출력 순서는 정해져 있지 않아 예제에서는 결과를 `sorted()`로 정렬했어요.

## 이름표로 찾는 딕셔너리

동아리 동물 뜻 사전에서 `dog`는 강아지, `cat`은 고양이, `cow`는 소, `rabbit`은 토끼를 뜻해요. 처음에는 `lion`의 뜻을 호랑이로 잘못 적어 두었어요. 이를 사자로 고치고 `tiger`와 호랑이를 새로 추가해 볼게요.

```python
word_dict = {
    'dog': '강아지', 'cat': '고양이', 'cow': '소',
    'rabbit': '토끼', 'lion': '호랑이'
}
print(word_dict.keys())
print(word_dict.values())
word_dict['lion'] = '사자'
word_dict['tiger'] = '호랑이'
print(word_dict)
print(word_dict.get('rabbit'))
```

실행 결과예요.

```text
dict_keys(['dog', 'cat', 'cow', 'rabbit', 'lion'])
dict_values(['강아지', '고양이', '소', '토끼', '호랑이'])
{'dog': '강아지', 'cat': '고양이', 'cow': '소', 'rabbit': '토끼', 'lion': '사자', 'tiger': '호랑이'}
토끼
```

`keys()`와 `values()`는 각각 키와 값을 보여 주는 뷰를 돌려줘요. 실제 리스트가 필요하면 `list(word_dict.keys())`처럼 `list()`로 감싸요. 대괄호는 위처럼 값을 고치거나 추가할 때 쓸 수 있어요. `get()`으로 없는 키를 찾으면 기본적으로 `None`이 나오므로, 꺼낸 값이 있는지 확인할 수 있어요.
