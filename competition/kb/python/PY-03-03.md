# PY-03-03 리스트 컴프리헨션·map·2차원 리스트
## 리스트 컴프리헨션으로 만들기

리스트 컴프리헨션은 반복하면서 새 리스트를 한 줄로 만드는 방법이에요. 기본 모양은 `[표현식 for 변수 in 반복할_대상]`이에요. 반복할 때마다 표현식을 계산해 결과를 리스트에 차례로 담아요.

꿈틀 중학교 코딩 동아리의 도장 실습에서는 한 묶음에 도장 5개를 담아요. 묶음 수를 입력받아 첫 묶음부터 해당 묶음까지의 도장 수를 구해 볼게요. 다음 코드는 양의 정수를 입력받는다고 가정해요.

```python
num = int(input())
five_list = [5 * n for n in range(1, num + 1)]
print(five_list)
```

입력이 `3`일 때의 실행 결과예요.

```text
[5, 10, 15]
```

`input()`은 입력을 문자열로 받으므로 `int()`로 정수로 바꿔요. `range`는 끝 숫자를 포함하지 않아서 `num + 1`을 썼어요. 입력 안내 문구가 결과에 섞이지 않도록 `input()`의 괄호는 비워 두었어요.

이 과정에서는 리스트 컴프리헨션 안에 for를 한 번만 쓰고, 이중 반복이 필요하면 일반 for 문으로 쓴다. 반복이 겹치는 예는 아래 2차원 리스트에서 확인해요.

## 조건에 맞는 값만 고르기

컴프리헨션의 반복 부분 뒤에 `if 조건`을 붙이면 조건이 참인 값만 새 리스트에 담을 수 있어요. 동아리의 숫자 선별 실습에서는 0부터 입력한 최댓값까지 검사해요. 3으로 나눈 나머지가 2인 수를 고른 뒤, 그 수를 각각 3배로 만들어요.

```python
maximum = int(input())
three_list = [n * 3 for n in range(maximum + 1) if n % 3 == 2]
print(three_list)
```

최댓값으로 `10`을 입력하면 실행 결과는 다음과 같아요.

```text
[6, 15, 24]
```

먼저 조건을 만족하는 수는 2, 5, 8이에요. 맨 앞의 `n * 3`은 고른 수를 리스트에 담기 전에 어떻게 바꿀지 정해요. 조건에 맞는 수가 없으면 빈 리스트가 만들어져요.

## map으로 한꺼번에 바꾸기

`map(함수, 반복할_대상)`은 대상의 각 값에 함수를 적용해요. 동아리의 점수 입력 실습에서는 쉼표로 구분한 점수를 정수 리스트로 바꿔요. 예를 들어 입력 문자열을 직접 정해 연습할 수 있어요.

```python
text = '6,14,15,20,27'
pieces = text.split(',')
scores = list(map(int, pieces))
print(scores)
```

실행 결과예요.

```text
[6, 14, 15, 20, 27]
```

`split(',')`은 쉼표를 기준으로 문자열을 나누어요. 나뉜 값은 아직 문자열이므로 `map`으로 각각에 `int`를 적용하고, `list`로 결과를 리스트로 만들어요. 정수로 바꿀 수 없는 조각이 있으면 오류가 나므로 입력을 확인해야 해요.

## 2차원 리스트 살펴보기

2차원 리스트는 리스트 안에 리스트를 담은 형태예요. 동아리 점수판 실습에서는 세 행의 점수를 각각 `[8, 14, 6]`, `[10, 12, 26]`, `[22, 14, 9]`로 정해요. 바깥쪽 인덱스는 행, 안쪽 인덱스는 열을 고르며 둘 다 0부터 시작해요.

```python
board = [[8, 14, 6], [10, 12, 26], [22, 14, 9]]
num1 = board[0][1]
num2 = board[1][0]
sum_row = sum(board[1])
sum_column = 0
for row in board:
    sum_column += row[1]
print(num1, num2)
print(sum_row, sum_column)
```

실행 결과예요.

```text
14 10
48 40
```

`board[0][1]`은 첫째 행의 둘째 값이에요. `sum(board[1])`은 둘째 행의 합이고, 반복문은 각 행의 둘째 값을 더해 둘째 열의 합을 구해요. 모든 칸을 차례로 살펴보려면 바깥 `for`로 행을 고르고, 그 안의 `for`로 행의 값을 하나씩 고르면 돼요.
