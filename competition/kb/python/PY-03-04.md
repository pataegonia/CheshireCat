# PY-03-04 중간 실력 확인 문제로 복습하기
## 중간 실력 확인 준비하기

꿈틀 중학교 코딩 동아리의 실습 예제로 조건문과 반복문, 리스트를 복습해요. 이 과정의 중간 실력 확인은 4문제이며, 3문제 이상 맞히면 4단원이 열려요. 아래 코드를 보기 전에 각 문제를 먼저 풀고, 예시 입력과 출력으로 결과를 확인해 보세요.

각 코드는 서로 독립된 프로그램이에요. 예시 입력은 `input()`이 읽을 내용이고, 실행 결과는 화면에 출력되는 내용이에요. 채점할 때는 안내 문구를 추가하지 않고 `input()`의 괄호를 비워 두어요. 출력할 때도 띄어쓰기와 줄바꿈을 지시한 형식에 맞춰요.

## 학점 계산하기

꿈틀 중학교 성적표 실습에서는 중간고사와 기말고사 점수를 공백으로 구분해 입력해요. 각 점수는 0점 이상 100점 이하예요. 평균이 90점 이상이면 A+, 80점 이상 90점 미만이면 A0, 60점 이상 80점 미만이면 B0, 40점 이상 60점 미만이면 C0, 40점 미만이면 F를 출력해요.

높은 기준부터 검사하면 앞의 조건을 통과하지 못한 경우만 다음 조건에서 확인해요. 나누기 연산자 `/`를 사용하므로 평균에 소수점이 있어도 그대로 비교할 수 있어요.

```python
mid, final = map(int, input().split())
avg = (mid + final) / 2
if avg >= 90:
    print('A+')
elif avg >= 80:
    print('A0')
elif avg >= 60:
    print('B0')
elif avg >= 40:
    print('C0')
else:
    print('F')
```

예시 입력:
```text
80 65
```
실행 결과:
```text
B0
```

## 다이아몬드 그리기

꿈틀 동아리의 다이아몬드 실습에서는 오른쪽 절반만 별로 그려요. 크기 `n`은 1 이상 100 미만의 정수예요. 첫 줄부터 별을 하나씩 늘려 `n`번째 줄에 별 `n`개를 찍고, 이후에는 하나씩 줄여 마지막에 별 하나를 찍어요.

첫 번째 반복문은 가장 긴 줄까지 만들고, 두 번째 반복문은 그보다 하나 적은 별부터 거꾸로 만들어요. 문자열에 정수를 곱하면 같은 문자를 반복할 수 있어요.

```python
n = int(input())
for i in range(1, n + 1):
    print('*' * i)
for i in range(n - 1, 0, -1):
    print('*' * i)
```

예시 입력:
```text
4
```
실행 결과:
```text
*
**
***
****
***
**
*
```

## 과일 바구니

꿈틀 동아리의 과일 바구니 실습에는 가격이 같은 바구니 3개가 있고, 바구니마다 과일이 4개씩 들어 있어요. 한 줄에 한 바구니의 과일 무게 4개를 공백으로 구분해 입력해요. 각 과일의 무게는 1 이상 100 미만이에요. 가장 무거운 바구니의 총 무게만 출력하며, 공동으로 가장 무거운 바구니가 있어도 그 무게를 한 번만 출력해요.

`sum()`으로 한 바구니의 무게를 합하고 리스트에 저장해요. 세 바구니를 모두 살펴본 뒤 `max()`로 가장 큰 합을 찾아요. 바구니의 번호가 아니라 무게를 출력한다는 점에 주의해요.

```python
totals = []
for _ in range(3):
    weights = map(int, input().split())
    totals.append(sum(weights))
print(max(totals))
```

예시 입력:
```text
3 4 3 2
4 5 2 3
1 6 5 4
```
실행 결과:
```text
16
```

## 야구 점수판

꿈틀 동아리의 야구 점수판 실습에서는 두 팀이 각각 9회의 득점을 한 줄씩 입력해요. 한 회의 득점은 0점 이상 10점 이하예요. 각 회에서 득점이 더 높은 팀에 점수판 점수 1점을 주고, 같은 회의 득점이 같으면 어느 팀에도 점수를 주지 않아요. 첫 번째 줄 팀의 점수를 콜론 왼쪽에 출력해요.

`zip()`은 두 리스트에서 같은 위치의 값을 짝지어요. 각 짝을 비교해 점수판 점수를 따로 세므로, 실제 득점의 합을 비교하는 것과는 결과가 다를 수 있어요.

```python
a = list(map(int, input().split()))
b = list(map(int, input().split()))
score_a = 0
score_b = 0
for x, y in zip(a, b):
    if x > y:
        score_a += 1
    elif x < y:
        score_b += 1
print(f'{score_a}:{score_b}')
```

예시 입력:
```text
1 0 3 6 1 0 8 7 3
3 1 0 5 1 1 6 5 2
```
실행 결과:
```text
5:3
```

## 질문으로 마무리하기

### Q. 평균이 정확히 80점이면 어떤 학점인가요?
A. 80점 이상 조건에 해당하므로 A0예요.

### Q. 다이아몬드 크기가 1이면 어떻게 되나요?
A. 첫 번째 반복문에서 별 하나를 출력하고 두 번째 반복문은 실행되지 않아요.

### Q. 바구니의 총 무게가 서로 같으면 어떻게 하나요?
A. 가장 큰 총 무게를 한 번만 출력해요.

### Q. 야구 점수판에서 한 회가 동점이면 어떻게 하나요?
A. 두 팀 모두 그 회의 점수판 점수를 얻지 않아요.
