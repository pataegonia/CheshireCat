# PY-04-01 함수 만들기와 반환값
## 함수와 매개변수
함수는 자주 쓰는 동작을 묶어 놓은 코드예요. `def`로 함수를 정의하고, 이름 뒤에 괄호를 붙여 호출해요. 이 과정의 함수 이름은 동사로 시작하는 영어 소문자와 밑줄로 지어요. 예를 들어 `get_total`은 합계를 구하는 함수의 이름이에요.

매개변수는 함수를 정의할 때 전달받은 값을 담는 변수이고, 인자는 함수를 호출할 때 전달하는 값이에요. 매개변수는 필요할 때만 만들며, 기본값을 정해 두면 인자를 생략할 수도 있어요. 다른 인자를 전달하면 기본값 대신 그 값을 사용해요.

꿈틀 중학교 코딩 동아리의 점수 차이 연습에서는 두 번째 점수의 기본값을 2로 정해요. 아래에서 `a`와 `b`는 매개변수이고, 호출할 때 쓴 5, 7, 4는 인자예요. 첫 호출에서는 `b`에 기본값 2가 들어가요.

```python
def get_difference(a, b=2):
    return a - b

print(get_difference(5))
print(get_difference(7, 4))
```

실행 결과:
```text
3
3
```

`return`은 함수의 실행을 끝내고 결과를 호출한 곳에 돌려줘요. `print`는 값을 화면에 보여 줄 뿐 반환하지는 않아요. 값을 반환하지 않는 함수는 기본적으로 `None`을 돌려줘요.

## 반환값을 여러 개 받기
꿈틀 동아리의 곱셈과 나눗셈 연습에서는 정수 두 개를 한 줄에 하나씩 입력해요. 이 연습에서는 두 번째 정수를 0이 아닌 수로 입력해요. 결과는 곱을 먼저, 나눈 몫을 나중에 출력해요. 아래 예시는 첫 정수 7과 둘째 정수 3을 사용해요.

```python
def get_product(a, b):
    return a * b

def get_quotient(a, b):
    return a // b

first = int(input())
second = int(input())
print(get_product(first, second))
print(get_quotient(first, second))
```

입력:
```text
7
3
```
실행 결과:
```text
21
2
```

`//`는 나눈 결과를 내림한 정수를 구하므로 음수를 다룰 때도 주의해요. 두 결과를 한꺼번에 받고 싶다면 `return` 뒤에 쉼표로 구분해 써요. 이렇게 반환한 값은 튜플로 묶이며, 여러 변수에 순서대로 나누어 저장할 수 있어요.

```python
def get_results(a, b):
    return a * b, a // b

product, quotient = get_results(7, 3)
print(product, quotient)
```

실행 결과:
```text
21 2
```

함수 안에 `return`을 여러 개 쓸 수는 있지만, 실행 중 하나를 만나면 함수가 끝나요. 따라서 두 값을 함께 돌려줄 때는 위처럼 한 `return`에 함께 적어요.

## 전역변수와 지역변수
함수 밖에서 만든 변수는 전역변수, 함수 안에서 만든 변수는 지역변수예요. 꿈틀 동아리의 변수 확인 예제에서는 전역 문자열을 `동아리`로, 지역 문자열을 `모둠`으로 정해요. 이름이 같아도 함수 안에서 새 값을 대입하면 별도의 지역변수가 만들어져요.

```python
label = '동아리'

def get_label():
    label = '모둠'
    return label

print(label)
print(get_label())
```

실행 결과:
```text
동아리
모둠
```

함수 안에서 같은 이름의 지역변수를 사용하면 그 지역변수가 선택돼요. 지역변수는 보통 그 함수 안에서만 사용할 수 있어요. 전역변수는 함수 안에서도 읽을 수 있고, 전역변수에 새 값을 대입하려면 함수 안에서 `global`을 선언할 수 있어요. 다만 값을 전달하고 반환하는 방식이 흐름을 이해하기 쉬워요.

## 람다로 간단한 함수 만들기
`lambda`는 간단한 함수를 한 표현식으로 만드는 방법이에요. `lambda x: x * x`는 인자 `x`의 제곱을 반환해요. 꿈틀 동아리의 제곱 연습에서는 정수를 3개 이상 7개 미만으로 공백으로 구분해 입력해요. 이 연습에서는 각 정수의 제곱을 새 리스트에 순서대로 저장해요.

```python
get_square = lambda x: x * x
numbers = list(map(int, input().split()))
squared_numbers = [get_square(n) for n in numbers]
print(squared_numbers)
```

입력:
```text
1 2 3 4 5
```
실행 결과:
```text
[1, 4, 9, 16, 25]
```

`split()`은 입력을 공백을 기준으로 나누고, `map(int, ...)`는 나눈 문자열을 정수로 바꿔요. 리스트 안의 식은 각 정수에 함수를 적용해 새 결과를 모아요.
