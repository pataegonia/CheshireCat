## 모듈 불러오기

모듈은 함수나 변수 등을 담아 재사용하는 단위예요. 직접 만든 파이썬 파일도 모듈이 될 수 있어요. `import 모듈명`으로 불러온 뒤 온점으로 모듈 안의 이름에 접근해요.

꿈틀 동아리의 문자열 실습에서는 미리 준비한 `string_op.py`의 `reverse_string`이 문자열을 뒤집고, `remove_whitespace`가 공백을 제거해요. 영어 문장을 한 줄 입력받아 두 결과를 차례로 출력해 봐요.

```python
import string_op

문장 = input()
print(string_op.reverse_string(문장))
print(string_op.remove_whitespace(문장))
```


`from string_op import reverse_string`처럼 필요한 함수를 가져오면 `reverse_string(문장)`으로 바로 사용할 수도 있어요.

## 모듈 만들기와 직접 실행

이번 계산 실습에서는 `calculate.py`를 만들어요. `multi`는 두 수의 곱을, `div`는 첫 번째 수를 두 번째 수로 나눈 값을 반환해요. 나누는 수는 0이 아니어야 해요.

```python
def multi(a, b):
    return a * b

def div(a, b):
    return a / b

if __name__ == "__main__":
    print(multi(10, 2))
    print(div(10, 2))
```

이 파일을 직접 실행한 결과예요.

```text
20
5.0
```

직접 실행한 모듈의 `__name__`은 `"__main__"`이므로 조건문 안이 실행돼요. 다른 파일에서 `import calculate`로 불러오면 함수는 사용할 수 있지만 조건문 안은 실행되지 않아요. 이렇게 시험용 실행과 재사용을 구분해요.

## math와 random

파이썬의 `math` 모듈에는 수학 계산에 쓸 값과 함수가 있어요. 꿈틀 동아리의 원 넓이 실습은 반지름을 10으로 정하고, 이어서 3의 7제곱을 구해요.

```python
import math

print(10 * 10 * math.pi)
print(math.pow(3, 7))
```

실행 결과예요.

```text
314.1592653589793
2187.0
```

`random`은 무작위처럼 보이는 값을 만들어요. 이 과정에서 `random` 모듈을 쓰는 실습은 채점 결과가 매번 같도록 첫 줄에 `random.seed(2024)`를 써요. 아래처럼 첫 줄에서 모듈을 먼저 불러온 뒤 세미콜론으로 이어 쓸 수 있어요. 동아리 추첨 실습에서는 1부터 50까지의 정수 중 하나를 뽑아요.

```python
import random; random.seed(2024)

print(random.randrange(1, 51))
```

실행 결과예요.

```text
31
```

`randrange(1, 51)`은 51을 포함하지 않아요. `random.sample(range(1, 51), 4)`를 쓰면 그 범위에서 서로 다른 정수 4개를 리스트로 뽑아요.

## 패키지

패키지는 관련 모듈을 묶은 단위이며 다른 패키지도 담을 수 있어요. 꿈틀 동아리의 별도 패키지 실습에서는 `string_op` 패키지 안의 `remove` 모듈이 공백을 지우고, `reverse` 모듈이 문자열을 뒤집어요. 앞의 `string_op.py` 모듈 실습과는 따로 준비해요.

이 실습의 패키지에는 `__init__.py`가 있으며, 패키지를 처음 불러올 때 `string_op 패키지가 열렸습니다.`를 출력해요. 이미 준비된 패키지를 다음처럼 사용해요.

```python
from string_op.remove import remove_whitespace
from string_op.reverse import reverse_string

문장 = input()
print(remove_whitespace(문장))
print(reverse_string(문장))
```

입력과 실행 결과예요. 안내 문구는 입력보다 먼저 나타나요.

```text
string_op 패키지가 열렸습니다.

```

## 용어 정리

- **모듈**: 함수와 변수 등을 담아 불러 쓸 수 있는 단위예요.
- **패키지**: 관련 모듈과 다른 패키지를 묶는 단위예요.
- **시드**: 무작위 값의 생성 순서를 정할 때 사용하는 시작값이에요.
- **`__main__`**: 직접 실행한 모듈을 구분할 때 쓰는 이름이에요.
