# PY-04-03 파일 다루기와 예외 처리
## 파일의 위치 찾기

파일을 열 때는 파일의 위치를 알려 주는 경로가 필요해요. 절대 경로는 파일 시스템의 맨 위인 루트부터 파일까지의 위치를 나타내요. 상대 경로는 현재 작업 디렉터리, 즉 프로그램이 작업을 시작한 위치를 기준으로 나타내요. 따라서 같은 상대 경로라도 작업 디렉터리가 달라지면 다른 파일을 가리킬 수 있어요. 작업 디렉터리는 파이썬 코드 파일이 있는 디렉터리와 항상 같지는 않아요.

꿈틀 중학교 코딩 동아리의 과일 기록 파일 이름은 `basket.txt`예요. 아래 실습에서는 이 파일이 현재 작업 디렉터리에 있다고 가정해요. 파일 이름만 적는 것도 상대 경로를 쓰는 방법이에요.

## 파일 열고 읽고 쓰기

이 과정의 파일 실습은 `open`을 쓸 때 항상 `encoding='utf-8'`을 적고 `with` 문으로 열어요. 인코딩은 글자를 파일에 저장하고 읽는 방식이에요. `with` 문 안에서 작업하면 블록을 벗어날 때 파일이 자동으로 닫혀요.

(표: PY-04-03-table1.csv)

`write`는 문자열을 그대로 쓰므로 줄을 바꾸려면 `\n`을 직접 넣어요. `readline`은 한 줄을, `readlines`는 남은 줄 전체를 리스트로 읽어요. `strip`은 문자열 양 끝의 공백과 줄바꿈을 제거해요.

## 과일 기록 분석하기

이 실습의 과일 기록은 한 줄에 과일 이름과 개수를 쉼표로 구분해요. 첫 기록은 사과 세 개, 둘째 기록은 배 두 개예요. 다음 코드는 먼저 파일을 새로 쓰고 다시 열어 개수의 합을 구해요. `split(',')`으로 나눈 개수는 문자열이므로 `int`로 바꾸어 더해요.

```python
with open('basket.txt', 'w', encoding='utf-8') as f:
    f.write('사과,3\n')
    f.write('배,2\n')

with open('basket.txt', 'r', encoding='utf-8') as f:
    첫줄 = f.readline().strip()
    나머지 = f.readlines()

합계 = 0
for 줄 in [첫줄] + 나머지:
    이름, 개수 = 줄.strip().split(',')
    합계 += int(개수)
    print(이름, 개수)
print('과일 합계:', 합계)
```

실행 결과예요.

```text
사과 3
배 2
과일 합계: 5
```

이 코드를 다시 실행하면 `w` 모드 때문에 이전 기록은 지워져요. 기존 기록을 보존하며 추가하려면 `a` 모드를 써요.

## 예외를 처리하고 직접 발생시키기

예외는 프로그램이 실행되는 동안 생기는 문제로, 처리하지 않으면 실행이 중단될 수 있어요. `try` 안에서 문제가 생기면 해당 예외 이름을 쓴 `except`에서 처리해요. 이 과정에서는 `except` 뒤에 예외 이름을 반드시 쓰고, 이름 없는 `except`는 쓰지 않아요. `as`로 예외를 변수에 담으면 자세한 내용도 확인할 수 있어요.

동아리 나눗셈 실습에서는 60을 입력받은 정수로 나누어요. 정수로 바꿀 수 없는 입력은 `ValueError`, 0으로 나누는 시도는 `ZeroDivisionError`로 처리해요.

```python
try:
    수 = int(input())
    print(60 / 수)
except ValueError as 오류:
    print('정수를 입력해요:', 오류)
except ZeroDivisionError as 오류:
    print('0으로 나눌 수 없어요:', 오류)
```

입력이 `0`일 때 실행 결과예요.

```text
0으로 나눌 수 없어요: division by zero
```

동아리 과일 기록에서 개수가 음수이면 잘못된 기록으로 정해요. 조건에 맞지 않을 때는 `raise`로 직접 예외를 발생시킬 수 있어요. 아래 코드는 발생한 `ValueError`를 바로 잡아 설명을 출력해요.

```python
개수 = -1
try:
    if 개수 < 0:
        raise ValueError('과일 개수는 음수일 수 없어요.')
    print('기록할 개수:', 개수)
except ValueError as 오류:
    print(오류)
```

실행 결과예요.

```text
과일 개수는 음수일 수 없어요.
```

파일이 없을 때는 `FileNotFoundError`처럼 상황에 맞는 예외를 처리할 수 있어요. 반면 코드의 문법이 잘못된 구문 오류는 보통 해당 코드가 실행되기 전에 발견되므로 코드를 고쳐야 해요.
