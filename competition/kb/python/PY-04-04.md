# PY-04-04 과정 전용 실습 도우미 kkumtle
## 꿈틀 도우미 만나기

꿈틀 중학교 코딩 동아리의 실습에서는 답을 확인하거나 자료를 정리할 때 도우미를 쓸 수 있어요. `kkumtle`은 이 과정의 실습 화면에서만 쓸 수 있는 도우미 모듈이에요. 실제 파이썬 패키지가 아니므로 일반 파이썬 실행 환경에 설치되어 있다고 생각하면 안 돼요.

모듈은 관련된 기능을 모아 둔 것이에요. 사용하기 전에 아래처럼 불러오고, 함수 앞에 모듈 이름과 점을 붙여요. 점 뒤에는 쓰고 싶은 함수의 이름을 적어요.

```python
import kkumtle
```

이 문장만 실행하면 화면에 출력되는 내용은 없어요. 같은 실습 코드에서 아래 예제를 따라 할 때는 맨 앞에 이 불러오기 문장을 넣어요.

## 어떤 함수가 있나요?

(표: PY-04-04-table1.csv)

괄호 안에 전달하는 값을 인자라고 해요. 함수마다 필요한 인자의 개수와 종류가 달라요. 표에서 `내_답`과 `정답`은 실제로 확인할 값을 넣는 자리를 뜻해요.

## 답과 힌트 확인하기

`check`는 두 값이 같으면 `정답!`을 출력하고 `True`를 돌려줘요. 다르면 `다시 해 볼까요?`를 출력하고 `False`를 돌려줘요. 돌려받은 값을 변수에 저장하면 나중에 다시 사용할 수 있어요.

```python
import kkumtle

결과 = kkumtle.check(5, 5)
print(결과)
kkumtle.check(4, 5)
```

실행 결과:

```text
정답!
True
다시 해 볼까요?
```

마지막 줄의 `check`도 `False`를 돌려주지만, 코드에서 그 값을 출력하거나 저장하지 않았어요. 그래서 실행 결과에는 함수가 직접 출력한 문구만 보여요.

`hint`는 힌트를 직접 출력하는 대신 한 줄 문자열로 돌려줘요. 이 과정에서 실습 2의 힌트는 `점수끼리 더해 보세요.`예요. 돌려받은 힌트를 보고 싶으면 다음처럼 `print`를 사용해요.

```python
import kkumtle

도움말 = kkumtle.hint(2)
print(도움말)
```

실행 결과:

```text
점수끼리 더해 보세요.
```

힌트는 실습 하나에 3번까지만 볼 수 있어요. 바로 답을 찾기보다 먼저 스스로 생각해 보고, 막히는 부분이 있을 때 사용해요.

## 자료를 표로 보기

`show_table`에는 리스트 안에 행마다 리스트를 넣은 2차원 리스트를 전달해요. 꿈틀 중학교 과일 바구니 예제에는 사과 3개와 배 2개가 들어 있어요. 첫 행에는 열의 이름을 넣어 자료가 무엇을 뜻하는지 알아보기 쉽게 만들어요.

```python
import kkumtle

바구니 = [["과일", "개수"], ["사과", 3], ["배", 2]]
kkumtle.show_table(바구니)
```

실행 결과는 다음처럼 칸을 맞춘 표 모양이에요.

```text
과일  개수
사과  3
배    2
```

`show_table`이 표를 직접 출력하므로 결과를 보기 위해 바깥에 `print`를 붙일 필요는 없어요. 표로 보여 주는 기능과 원래 리스트에 값을 저장하는 일도 구분해요.

## 일반 파이썬 함수와 비교하기

`kkumtle` 함수는 이 과정의 실습을 돕도록 정해진 기능이에요. 반면 `print`와 `len`처럼 파이썬에 기본으로 들어 있는 함수는 `kkumtle`을 불러오지 않아도 사용할 수 있어요. 예를 들어 `len(바구니)`는 바구니 리스트의 행 수를 돌려주지만, `kkumtle.show_table(바구니)`는 그 내용을 표로 출력해요.

어떤 함수를 쓰든 괄호에 무엇을 넣는지, 함수가 화면에 직접 출력하는지 값을 돌려주는지 살펴보는 습관이 중요해요. 특히 `check`는 출력과 반환을 모두 하고, `hint`는 힌트 문자열을 돌려준다는 차이를 기억해요.
