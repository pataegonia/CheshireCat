## 모자람과 대안 (GP1 S1.1 "리스크 → 대응" 행 발동)

대체 교재에 코드 절이 하나, 민감 교과 절이 없다. GP1 문서의 대응은 "라이선스가 같은 공개 자료에서 청크 20–24개를 `aux_chunks.jsonl`로 더한다. 못 구하면 T7·민감 하위 유형을 빼고 리포트에 적는다"이다. 선택지는 다음과 같고, 결정은 GP1 S1.1 착수(11/4–11/5) 전에 사용자가 한다.

1. (추천) 교재와 같은 방식으로 **자체 집필** aux 청크 24개를 만든다(CC-BY-4.0, Sonnet 초안 + 본인 검산). 코드 12개(측정값 처리 짧은 파이썬: 최댓값·범위·단위 변환·반올림), 민감 교과 12개(감염병 예방 원리, 백신 개념, 전쟁과 과학 기술의 역사 같은 교과 수준). 기존 교과서·위키 문장은 옮기지 않는다. 약 1h.
2. 주최측 교재가 11/6까지 오면 그 교재에서 고른다(master-plan §8).
3. T7(코드 출력)과 민감 하위 유형을 빼고 리포트에 적는다(주입 258 → 234, 정상 300 → 252. GR-08 크기 기준 ≥250·≥300 중 정상이 미달).
