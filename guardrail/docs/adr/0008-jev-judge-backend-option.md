# ADR-0008: 판정 백엔드 선택지로 TypeSafe Jev

**Date**: 2026-10-30
**Status**: proposed
**Deciders**: danielcho02
**PRD**: GR-02, GR-04, §11, §12

## Context

입력 판정에는 범주 S0–S14 중 하나와 5단계 대응 중 하나를 고르는 일만 필요하다. 그런데 범용 LLM 판정기에는 두 가지 한계가 있다.
- JSON 형식이 깨질 수 있어서 재시도와 기본값 처리가 필요하다.
- 판정기가 내는 확신도가 실제로 맞을 확률과 일치하지 않는다. 그래서 "정상 오차단 ≤1%" 같은 통계적 보장을 할 수 없다(ADR-0002 Negative).

TypeSafe AI의 Jev는 글을 생성하지 않는 판정 전용 모델이다. 텍스트와 보기를 주면 보기 중 하나를 고르고, 보정된 확률을 함께 돌려준다. 3자 블로그에 따르면 판정 1회에 70–500ms가 걸린다.

Jev에 대해 확인하지 못한 것이 네 가지 있다.
- 한국어 성능
- 독립 벤치마크
- 공식 단가
- 공모전에서 엘리스 외 API를 써도 되는지

현재 접근은 대기 명단을 거치거나 Vercel AI Gateway, Cloudflare Workers AI를 통해야 한다.

## Decision

판정 백엔드를 설정값 `judge_backend: llm | jev`로 고를 수 있게 한다.
- 기본값은 `llm`이다.
- `jev`는 입력 판정(GR-04)에만 쓴다. 위기 플래그가 붙은 입력의 하위 분류(GR-02)도 이 입력 판정 호출 안에서 한다.
- GR-04 출력 스키마와의 대응은 다음과 같다.
  - `category`와 `action`은 보기 하나로 합성한다. 예를 들어 `S14:refuse`, 위기 플래그가 있으면 `S5:crisis_T1`처럼 만든다.
  - `confidence`는 Jev의 확률을 그대로 쓴다.
  - `rule_id`는 고른 보기 ID로 채운다.
  - `reason`은 null을 허용한다. Jev는 사유 문장을 주지 않는다.
- 교환 판정(근거·인용)에는 쓰지 않는다. ADR-0005의 근거 인용 확인에는 판정기가 인용문을 텍스트로 돌려줘야 하는데, Jev는 보기 선택과 확률만 돌려준다.

`jev`는 아래 전제 조건을 모두 만족할 때만 켠다.
1. 주최측이 엘리스 외 외부 판정 API 사용을 허용한다(리더를 통해 확인).
2. 개발 세트 100건 이상에서 `llm`과 비교해 차단율과 과잉 거절이 같거나 더 낫다.
3. 실제 학생 정보가 들어 있는 데이터는 보내지 않는다(REQ-20, 개인정보 국외 이전).
4. API 키를 확보한다. 키는 환경변수로만 다룬다.

## Alternatives Considered

### LLM 판정기만 사용
- **Pros**: 의존성이 하나라 단순하다. 엘리스 API 안에서 모두 해결된다.
- **Cons**: 형식이 깨질 수 있고, 확률 보정이 되지 않는다.
- **Why not**: 기본값으로는 유지한다. 다만 비교할 대상이 없으면 판정 방식의 선택 근거를 보고서에 쓸 수 없다.

### Jev를 기본값으로 사용
- **Pros**: 형식이 안정적이고, 보정된 확률을 얻으며, 싸다(주장 기준).
- **Cons**: 한국어 성능이 검증되지 않았다. 주최측 허용 여부와 접근 승인을 모른다. 외부 의존이 생긴다.
- **Why not**: 4주 일정에서 핵심 경로를 확인되지 않은 외부 서비스에 걸 수 없다.

## Consequences

### Positive
- 판정 백엔드 비교(차단율, 과잉 거절, 지연, 비용)가 보고서의 실험 하나가 된다.
- Jev 확률이 잘 보정되어 있다면 입력 판정 임계값에 통계적 보장을 다시 붙일 수 있다(ADR-0002에서 보류한 Neyman-Pearson 방식).

### Negative
- 판정 인터페이스를 백엔드 두 개에 맞춰 추상화해야 한다. 함수 하나와 어댑터 두 개로 끝낸다.
- `jev` 경로의 테스트에는 모의 응답이 필요하다.

### Risks
- 주최측이 불허하거나 승인이 늦어질 수 있다. 기본값이 `llm`이므로 기능에는 영향이 없고, 비교 실험만 빠진다.
- 적대적 입력에 민감하다는 문서 경고가 있다. 비교 실험을 할 때 한국어 우회 세트를 반드시 포함한다.
