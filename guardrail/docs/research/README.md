## 1. 1차 조사에서 바뀐 결론

| 1차 결론 | 2차 조사 후 | 근거 |
|---|---|---|
| 1차 선별 분류기로 대부분 걸러냄 | **1차 선별은 확신 높은 것만 차단하는 보조 장치**. 판단의 주력은 LLM 판정 | 임베딩 분류기는 처음 보는 공격 유형에서 AUC 8–16%p 하락, 놓친 공격에도 0.99 확신. 기존 탐지기는 FPR 1%에서 공격 2–20%만 탐지 (R6) |
| 근거 이탈 탐지 ≥0.9, 오탐 ≤5% | **명백히 주입된 오류에서만 현실적**. 유형별로 따로 보고 | API 검사기 균형 정확도 74–76% (LLM-AggreFact), 한국어 멀티턴 RAG에서 GPT-4o 0.715 (R7) |
| 근거 검사는 주장 분해 | **문장 단위 + 문장당 최대 3개 하위 주장**. 과도한 분해는 오히려 정확도 하락 | MiniCheck WiCE 80.0 → 71.1 (R7) |
| 수리 = 재생성 | **삭제 우선, 재생성은 검사 결과를 근거로 1회**. 근거 없이 "다시 생각해"는 금지 | 단순 자기 교정이 정확도를 75.8 → 38.1로 떨어뜨림 (R7) |
| 스트리밍 응답 | **완성 후 검사하고 표시** ("교재 확인 중…") | 비동기 필터는 차단 전 노출 발생 (Azure·AWS 문서, R7·R8) |
| 위협의 중심은 유해 요청 | **튜터에선 정답 유출과 대화 단위 우회가 가장 큼** | 적대적 학생이 유출률 14% → 82%, Qwen-32B 70%가 출력 재작성으로 4%, 추론형 튜터로 3% (R5). 국감에서 응답 단위 필터가 바꿔 말하기로 우회됨 (R9) |
| 생성 모델은 성능만 보고 선택 | **생성 모델 선택이 곧 1차 방어** | 한국어 적응형 공격 성공률: Claude-4.5-Sonnet 4.9%, GPT-5-mini 69.3% (R5) |

## 2. 아키텍처 사양

> **조사 시점(10/29)의 1차 제안이다. 현재 구조는 PRD §4, ADR-0002(학습 분류기 P2), ADR-0007(병렬 2호출, 문맥 확장)이 대체한다.** 아래 내용은 근거 기록으로 남긴다.

```
입력 ─▶ ① 전처리 ─▶ ② 1차 선별 ─┬─ 차단 (확신 높음)
                                 ├─ 통과 ──────────────┐
                                 └─ 애매 ─▶ ③ LLM 정책 판정 ─┤
        ④ 세션 위험 상승 ─▶ 대화 전체 재판정 ──────────────┤
                                                    ▼
                   검색 (임베딩 공유, ②와 병렬) ─▶ ⑤ 검색 가드 ─▶ 생성
                                                    ▼
          ⑥ 코드 검사 ─▶ ⑦ LLM 교환 판정 ─▶ ⑧ 수리 ─▶ 표시
```

| 단계 | 사양 | 근거 |
|---|---|---|
| ① 전처리 | 보이지 않는 문자 제거 → 정규화 → 자모 재조합(받침 결합) → 매칭 전용 "골격 뷰"(공백·숫자·기호 끼움 제거). 현재 순서는 ADR-0001. PII는 정규식+체크섬, 2020-10 이후 주민번호는 체크섬 실패를 "낮은 신뢰도"로. p95 ≤10ms | NFKC만으로는 자모가 반만 복원됨 (R5 직접 확인) |
| ② 1차 선별 | KURE-v1(ONNX int8) + LogisticRegression, 대체 multilingual-e5-small. **차단 임계값**: Neyman-Pearson으로 정상 오차단 ≤α 보장(α=1%, δ=5%면 정상 표본 ≥299). **에스컬레이션 임계값**: 공격 재현율 기준(β=5%). 보정용 정상 표본 ≥1,000. 목표 에스컬레이션율 5–15% | R6 (표본 수 공식 직접 검산) |
| ③ LLM 정책 판정 | 안전/논쟁적/위험 3단. 정책 프롬프트는 지시·정의·기준·예시 400–600토큰, 출력은 결정+규칙 ID+짧은 사유. 스키마 강제 JSON, 1회 재시도 후 실패 시 범주별 기본값 | R1, R7 (프롬프트만으로 JSON 성공률 82.6%) |
| ④ 멀티턴 | `R_t = max(R_{t-1}, 0.7·R_{t-1}+0.3·s_t)`. **R은 차단하지 않고 재판정만 유발**. 재판정은 최근 8턴을 300–600토큰으로 압축해 LLM에 | R6, R9 REQ-05·11 |
| ⑤ 검색 가드 | 색인 시점 청크 인젝션 스캔(오프라인), 런타임 datamarking, 답변 링크·이미지 허용 목록 | R1 |
| ⑥ 코드 검사 | 카나리아(골격 뷰로도 비교해 구분자 우회 대비, 번역 유출은 LLM 판정 몫), PII 재검사, `[S#]`가 검색된 청크인지 | R5, R7 |
| ⑦ LLM 교환 판정 | 질문+최근 턴+근거+답변을 한 번에. 생성과 **다른 모델 계열**, temperature 0. 문장 라벨: SUPPORTED / INFERRED / PARTIAL / NOT_FOUND / CONTRADICTED / NO_CLAIM. 판정마다 ≤80자 인용 → 코드로 청크 안에 실재하는지 확인(없으면 NOT_FOUND). 점수 G<0.7, CONTRADICTED 1개, 핵심 문장 미지지 시 위반 | R7 (한국어 판정기 근거 날조 13–16건) |
| ⑧ 수리 | R0 유해·유출은 수리 없이 안전 템플릿 / R1 위반 문장이 1/3 이하면 삭제 / R2 판정 근거를 주고 재생성 1회 / R3 "교재에서 찾지 못했어요" + 지지된 문장. 정답 유출 판정 시 힌트로 재작성 | R7, R5 |
| 전제 | 모든 계층은 뚫린다. 도구 없음, 링크 제한, 균일한 거절 문구, 점수 비공개로 피해를 작게 | R1, R8 |

비용 추정: 출력 판정 답변당 1.25–1.4회 호출, 입력 약 4,300·출력 약 430토큰. 공식 단가 기준 gpt-4o-mini $0.0009, Claude Haiku 4.5 $0.0065. 엘리스 단가는 미공개.

## 3. 학생 안전 요구사항

학생용 가드레일은 차단과 응답 두 가지가 아니라 **허용 / 교육적 전환 / 부분 응답 / 거절 / 위기 프로토콜** 5단계로 대응한다. 범주는 R3의 S0–S14를 쓴다. R9가 이를 REQ-01–36으로 구체화했고, 그중 가드레일이 직접 구현할 MUST는 다음과 같다.

| 묶음 | 핵심 요구사항 |
|---|---|
| 위기 (REQ-01–08) | 차단하지 않고 위기 템플릿, 대화 유지 / 방법·도구·장소·치사량 절대 제공 안 함(비교·가정·역할극 포장 포함) / 비밀 유지 약속 안 함 / "극단적 선택" 등 금지 표현 필터 / 연락처는 설정 파일 1곳, 분기마다 공식 페이지와 재확인 |
| 실제 사고에서 나온 통제 (REQ-09–15) | 친구·연인·상담사 페르소나 금지 / 대화 단위 판정, 바꿔 말하기 재시도 차단 / P0 플래그는 반드시 응답+알림 / AI임을 처음과 주기적으로 고지 / 나이 모르면 최연소 기준 |
| 개인정보·법 (REQ-18–24) | 외부 LLM 전송 전 마스킹 / 정신건강 발화는 학습·프로파일링·장기 기억에 안 씀 / 생성형 AI 사전 고지(AI기본법 제31조①) / 채점 기능은 기본 꺼짐(켜면 고영향 AI, 제2조제4호 차목) |
| 교사 가시성 (REQ-27–31) | 심각도 P0–P3, P0 미확인 시 상위 전달 / 교사에게는 해당 메시지 ± 3턴만 / 경찰 자동 연락 없음 / 감정 점수 없음 |
| 학업 무결성 (REQ-32–36) | 힌트 사다리 L0(먼저 시도) – L4(전체 풀이) / 시험 시간은 교사·LMS 신호로만 판단, 텍스트 추측만으로 차단 안 함 |

응답 템플릿 3종(위기 T1, 괴롭힘 피해 T2, 그루밍 신호 T3)은 R9 §요구사항 목록에 있다. 연락처는 검증됨: 109, 마들랜(109 문자·카카오톡), 1388(전화·문자 1388), 117(문자 #0117), 디지털성범죄피해자지원센터 02-735-8994.

## 4. 운영 사양 (R8)

> **조사 시점(10/29)의 제안이다. 위기 처리와 장애 시 동작은 PRD GR-02·GR-14, 지연 목표는 PRD §6이 대체한다.** 특히 "위기 → 절대 차단 안 함"은 "막는 경우에도 위기 템플릿으로 응답"으로 재정의됐고, 첫 문장 표시 목표는 p95 ≤5s다.

| 항목 | 사양 |
|---|---|
| 지연 | 첫 문장 표시 p95 ≤3s, 에스컬레이션 시 ≤5s. LLM 판정 p95 1.5s·타임아웃 2.5s. 질문 임베딩은 한 번 계산해 분류기와 검색이 공유 |
| 가드 장애 시 | 탈옥·성적·위험 → 차단 / **위기 → 절대 차단 안 함, 연락처 항상 부착 + 교사 알림 대기** / PII 정규식 실패 → 로그 저장 중단 / 학업·범위 → 통과 / 근거 → "자료에서 확인되지 않음" 표시 |
| 보호 | 판정 오류율 20% 또는 연속 타임아웃 5회면 차단기 개방, 생성·판정 쿼터 분리, 판정 캐시는 정확 일치만, 사용자당 분당 10회·10분당 에스컬레이션 5회 |
| 로그 | HMAC 가명 ID(월별 키), 학년대만, 정책 버전·점수·조치·사유 코드·단계별 지연. 원문 기본 미저장, 마스킹 원문은 차단·에스컬레이션·이의·표본만 30일 |
| 피드백 | 위기·이의 100%, 차단 10%, 허용 1% 사람 검토. "잘못 막혔어요" → 정상 회귀 세트 |
| 배포 | 섀도 → 5% → 25% → 100%. 차단율 1.5배·이의 2배·p95 +500ms·위기 알림 급감 시 롤백 |
| 재보정 트리거 | 차단율 7일 연속 > 2α, 에스컬레이션율 목표의 0.5–2배 밖 3일, 분포 PSI >0.2, 공격 유형별 재현율 <80%, 월 1회 (R6) |

## 5. 평가 사양 (R8, R7, R5)

| 항목 | 사양 |
|---|---|
| 공격 성공률 | **사용자에게 실제로 보인 출력** 기준. StrongREJECT + 이진 판정기, 출력 길이 고정 |
| 적응형 공격 | 정적 세트 / 쿼리 예산(10·50·200)별 자동 공격 / 한국어 기법을 쓰는 사람 레드팀을 따로 보고 |
| 표본 수 | "차단율 ≥95%" 주장: 실패 0건이면 59건, 1–5건이면 93/124/153/181/208건 (직접 검산). 핵심 범주는 ≥124건, 전체 공격·정상 각 ≥600건. 59건 미만 범주는 "주장 불가" 표시. 변형은 원 요청(seed) 단위로 셈 |
| 근거 검사기 평가 | 위반 주입 ≥250건(7유형, 2개 모델 계열로 생성), 정상 답변 ≥300건, 실제 답변 300건 이중 라벨(100건 κ≥0.6). G 임계값 0.5–0.9 스윕 |
| 통계 | Wilson 구간 보고, "≥95%" 주장은 Clopper-Pearson. 설정 비교는 McNemar + Holm 보정. 항목당 3회 실행, 한 번이라도 뚫리면 실패 |
| 한국어 판정기 | 사람 라벨 150–200건과 Cohen κ |
| 테스트 매트릭스 | 범주 × 한국어 기법(자모·초성·야민정음·코드스위칭·로마자·왕복 번역·존댓말/반말·역할극) 약 7,300건. 학습/홀드아웃은 원 요청 단위로 나누고 정규화 후 중복 제거 (R5) |
| 상용 기준선 | OpenAI moderation(무료), AWS Bedrock Guardrails Standard(한국어 공식 지원, 약 $1.70/1k). 학생 데이터는 보내지 않고 공개 벤치마크만 |

## 6. 데이터 계획

1차 계획(R2) 유지. 원칙: 평가 원천은 학습에 쓰지 않고, 학습·보정은 평가 세트와 임베딩 유사도로 중복 제거, 번역은 따로.

| 용도 | 데이터 |

## 8. PRD 목표치 조정 제안

| 지표 | PRD 목표 | 조사 근거 | 제안 |
|---|---|---|---|
| 근거 이탈 탐지 / 오탐 | ≥0.9 / ≤5% | 공개 검사기 74–76% | 오류 유형별 보고. 명백한 주입 오류에서 ≥0.9, "교재에 없는 사실 추가"는 0.7–0.85를 현실적 목표로 |
| 공격 차단율 | ≥95% | 정적 세트에선 가능, 적응형 공격에선 대부분 방어가 90% 이상 뚫림 | 정적·자동·사람 레드팀 3단으로 나눠 보고 |
| 과잉 거절 | ≤5% | 1차 선별 단독으로 FPR 1%에서 탐지 2–20% | 캐스케이드 전체로 측정, 범주·학년대별 분해 |
| 정상 오차단 보장 | — | Neyman-Pearson으로 통계 보장 가능 | 보고서에 "α=1%, 95% 신뢰" 형태로 명시 |

## 9. 우리 기여가 될 수 있는 빈칸

공개 연구가 없어서 우리가 직접 측정하면 그대로 보고서 기여가 된다.
1. 한국어 우회 표기(자모·초성·야민정음)의 LLM 탈옥 효과와 정규화 방어 효과 측정 (선행 연구 없음)
2. 존댓말·반말이 거절 행동에 주는 영향 (선행 연구 없음)
3. 한국어 멀티턴·간접 인젝션·학생 안전 평가 세트 (공개 세트 없음)
4. 한국어 RAG 근거성 검사기 성능 (영어 검사기의 한국어 성능 직접 연구 없음)

## 10. 주최측 확인 필요 (리더 태권 님께 전달)

1. 엘리스 ML API: OpenAI 호환 여부, base URL·인증, **제공 모델 목록**(생성 모델 선택이 방어 성능을 좌우)
2. `response_format` JSON 스키마 강제 지원, 임베딩 엔드포인트
3. 팀별 크레딧, 모델별 단가, RPM/TPM, 동시성
4. 모델 가중치(KURE, Qwen3Guard-0.6B) 동봉 허용, 심사 환경 인터넷
5. 패키지 허용 목록과 설치 용량, CPU 코어·RAM(VNNI 지원 여부), 요청당 지연 제한
6. 비상업 라이선스 데이터 학습 사용 가능 여부
7. 대상 학생 연령대, 시험 시간 신호(LMS 연동) 존재 여부
8. 프레임워크 비교 대상 지정 여부
9. 실제 PII를 외부 API로 보내도 되는지

## 11. 남은 불확실성

- KURE-v1·Qwen3Guard-0.6B의 CPU 지연은 추정치뿐. 대상 하드웨어에서 실측 필요.
- GPT-4.1-mini·Claude Haiku 4.5급을 검사기로 쓴 공개 수치 없음.
- 중립적인 한국어 가드 모델 벤치마크 없음. Kanana Safeguard는 중립 비교에 없음.
- Guardrails AI Hub 종료일은 공식 문서끼리 8/6과 8/25로 상충.
- 몇몇 2026 논문(DeepContext, Defensive M2S, Confidently Wrong 등)은 초록·보도만 확인. 해당 메모에 표시.
