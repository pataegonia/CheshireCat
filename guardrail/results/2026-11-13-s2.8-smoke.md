| 항목 | 값 |

| 명령 | `python -m guardrail.eval.run --config configs/default.yaml --name s28-smoke` |
| 코드 | `gr/s2.8-assemble` `aff5246`(로컬 브랜치, 푸시 안 함), 설정 해시 `8a96cf56b9ab` |
| 판정기 | `Guard`: 저신호 직접 판정 → kNN 예시 8개 + 입력 nano ∥ 출력 nano → 3단 ①–④ + safe 규칙 |
| 데이터 | 홀드아웃을 뺀 320행(가드 160 + 튜터 160), 짝 묶음 5-분할 |

## 실패

| 역할 | 호출 | 실패 |
|---|---|---|
| 입력 판정 | 311 | 0 (`finish_reason=length` 0%) |
| 출력 판정 | 64 | **4 (6.3%)**: 잘림 3(`bad_json`·`length` 4.7%) + timeout 1(1.6%) |

- 출력 판정 실패가 2% 기준(R14-D8)을 다시 넘었다. 출력 단독 실측(800에서 4.7%)과 같은 양상이다. 실패 4행 중 3행이 ④의 기본값(`true/[]`)으로 떨어졌다.
- `max_completion_tokens`는 이 실행에서 바꾸지 않았다(800). 1600이면 잘림 0%·실패 1.0%였다(`2026-11-13-output-v1-solo.md`). S2.9에서 값을 정한다.

## 정리

- 조립본이 형식 오류 없이 끝까지 돈다. 가드 점수 79.38(1회).
- 점수를 깎는 곳은 순서대로 입력 block 판정(F1 0.77, 가중 0.45), 출력 ④의 놓침, 출력 호출 잘림이다.
