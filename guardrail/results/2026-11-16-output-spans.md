저장된 응답에 출력 조립 변형을 다시 걸어 실제 grader로 행 단위 재채점했다(API 0회). 대상은 공개 개발 분할의 후보 답변 64행(정답 구간 28행)이고, 홀드아웃은 열지 않았다.

- 스크립트: `scripts/r16/span_replay.py`. 출력 단 준비는 `Guard._prepare`를 그대로 부르고, 기록된 범주와 `output_judge` 응답으로 조립한다.
- 첫 검사로 "변형 없는 재생 = 기록된 (grounded, unsupported)"를 본다. 기록 4개(`s33-full-r1`, `v1en-en-r1..3`, 출력 프롬프트 1.1, 설정 6.0.5) 모두 64/64행이 같았다.

## 3. 출력 프롬프트 1.2 선별 (출력 단독 1회, 69호출 + probe 5) — 미채택

- 1.2는 `answer_quote` 지시만 바꿨다. 틀린 첫 낱말에서 시작하고, 도입은 빼고, 값 뒤나 절 끝에서 멈추고, 보통 30자 아래로 쓴다. 예시는 지어낸 것 1개다.
- 비교 대상은 1.1 기록 4개, 대상 행은 정답 범주가 block이 아닌 개발 행이다.

| 기준 (미리 고정) | 결과 | |
|---|---|---|
| 글자 그대로 옮긴 인용 ≥ 0.95 | 1.00 (25개) | O |
| 8자 미만 인용이 1.1보다 늘지 않음 | 3 대 0–1 | **X** |
| 같은 행 짝 인용 F1 Δ ≥ +0.05 | +0.076 ~ +0.119 | O |
| 0.2 넘게 나빠진 행 ≤ 2 | 2 / 3 / 3 / 4 | **X (3/4)** |

- 인용 모양은 좋아졌지만, 손실 두 가지가 그 이득을 상쇄했다.
  - **판정 뒤집힘:** 1.1이 근거 없음으로 잡던 행을 1.2가 근거 있음으로 바꿨다. `pub-d495c20a`는 4번 모두, `pub-9b375ba2`는 3번이다.
  - **8자 문턱:** 짧은 인용이 `quote_min_chars: 8`에 걸려 ④(근거 있음)로 떨어진다.
- 모양 때문에 나빠진 행은 1–2개다(정답보다 짧게 자름).
- 1회 실행이라 판정 뒤집힘이 nano의 흔들림인지 프롬프트 효과인지 가를 수 없다.
- 같은 틀(정답 범주로 조립)에서 1.2와 `quote_min_chars=1`을 함께 쓰면 +0.0168이다. 다시 볼 때는 문턱을 같이 설계하고, 같은 프롬프트를 반복 실행해 판정 흔들림의 폭부터 잰다.

## 4. 1.2 재실행으로 원인 분리 (`s31-oq12-r2`, 69호출 + probe 5)

| 비교 | 짝 ΔF1 | 0.2 넘게 나빠진 행 | 8자 미만 인용 |
|---|---|---|---|
| 1.2 r2 대 1.1 기록 4개 | +0.076 / +0.037 / +0.076 / +0.050 | 2 / 4 / 2 / 4 | 3 대 0–1 |
| 1.2 r1 대 1.1 기록 4개 (§3) | +0.119 / +0.076 / +0.112 / +0.087 | 2 / 3 / 3 / 4 | 3 대 0–1 |
| **1.2 r2 대 1.2 r1 (같은 프롬프트)** | −0.039 | **6** | 3 대 3 |

- **판정 뒤집힘은 잡음이다.** r1에서 인용이 사라진 행(`pub-d495c20a`, `pub-9b375ba2`)은 r2에서 다시 잡혔다. r2에서는 다른 행(`pub-5c77fd7e`, `pub-300f9442`)이 사라졌다. 같은 프롬프트 두 실행 사이에도 0.2 넘게 갈리는 행이 6개다. 그래서 "1회 실행 대 1회 실행에서 나빠진 행 ≤2"(기준 4)는 같은 프롬프트끼리도 통과하지 못한다. 기준을 잘못 세웠다.
- **모양 손실은 체계적이다.** 1.2가 정답보다 짧게 자르는 행이 두 실행 모두에서 나온다(`pub-94e2db73` 0.70→0.24, `pub-7fb64802` 0.84→0.56 등). 8자 미만 인용도 두 번 다 3개다(기준 2). 원인은 "보통 30자 아래, 문장 전체를 옮기지 말라" 지시로 본다(추정).
- **인용 이득은 있지만 r1보다 작다.** 8개 비교의 짝 ΔF1 평균은 약 +0.08이다(r1 +0.10, r2 +0.06). 같은 프롬프트 두 실행의 차이(0.04)와 비슷한 크기라, 1회 선별로는 확정할 수 없다.
- **결정은 그대로 미채택.** 다시 하려면 1.3에서 길이 지시를 빼고, `quote_min_chars`를 같이 낮추고, 같은 프롬프트 반복의 잡음 폭을 기준에 넣어 다시 설계한다.
