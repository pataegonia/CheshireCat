# 튜터 실측 총정리 (11/13~11/17): 무엇을 쟀고, 무엇이 통했고, 어디서 잃는가

> 새 세션·다른 팀원이 **이 문서 하나로 지금까지의 튜터 실측을 알고 다음 개선을 고를 수 있게** 모은 대장이다.
> - 범위: yang-co1(튜터 A)의 측정과, pataegonia(튜터 B·리더)·pyr27(통합)·danielcho02(가드)가 PR·이슈·결과 문서에 남긴 **튜터 점수 관련** 측정. 가드 자체 점수는 넣지 않았다.
> - 표시: **[실측]** = 측정한 사람이 결과 파일·제출 메시지로 낸 숫자, **[기록]** = 다른 문서·PR에서 옮긴 숫자(출처 적음), **[어림]** = 계산.
> - 질문·답·교재 본문은 넣지 않았다(SPEC §8). 행 단위 결과와 스크립트는 각 측정자의 개발 PC·런박스(git 제외)에 있다.
> - 점수는 모두 **튜터 점수**(문항 점수 평균 × 100)다. 총점은 가드 점수 흔들림이 커서 비교에 쓰지 않는다.

## 0. 한 화면 요약

1. **지금 main은 약 81점(PC 공개 교차 검증) / 78.5점(대회 비공개 표본)이다.** 같은 설정 23회 평균 80.86, SD 1.41 [기록 #195].
2. **대회 실제 제출에서 가장 높은 것은 B2(주 호출 ∥ E)와 C4(T·E·W 구조)로 둘 다 약 82.1점**이다. main(78.5)보다 +3.7. 가드형 결합(gc 계열)은 79.4~79.8로 main 수준이었다(2장).
3. **PC 같은 세션에서 가장 높은 것은 G0(주 호출 ∥ E ∥ T, kNN 예시 없음) 87.39로 B2보다 +4.1**(4-9). **실제 제출 3회 평균은 82.32로 지금까지 최고지만 B2·C4(82.14)와 구별되지 않는다.** B2·C4·G0이 모두 82점대에 모였다.
4. **PC에서 오른 만큼 제출에서 오르지 않는 경우가 있었다.** C4는 PC에서 B2보다 +1.9였지만 제출에서는 같았고, 가드형은 PC 측정 없이 냈더니 B2보다 −2.5였다. 공개 세트를 많이 보는 판단(kNN 예시·공개 행으로 다듬은 경계)일수록 비공개 표본에서 이득이 줄었다.
5. **주 호출 프롬프트·후처리만 바꾼 실험은 모두 구별 불가였다**(12종 이상, 4-1). 점수가 움직인 것은 **판단을 주 호출 밖의 짧은 호출로 뗀 것**뿐이다: E(자료에 있나), T(의도 이름표), 가드 classify + 신호 조건, 대행 덮기.
6. **리더의 동결 묶음**(대행 덮기 + 실패 때 자료 인용 답 + T serial)은 런박스 판정 포함 main 대비 **+4.3~5.4** [기록 #220]. 이 묶음에는 E(B2)가 없다. B2를 이 묶음 위에 얹은 측정은 아직 없다.
7. **남은 손실(PC, 같은 세션 최고 85.2 기준 약 15점)**: normal 7.3점(정답 사실 3.1 · 인용 2.2 · action 1.4 · 충실 0.6), harmful 2.4, out_of_material 1.6, off_topic 1.1, answer_seeking·academic 1.8. 판정 천장 약 5점(정답 답변도 94.84).
8. **비교 규칙**: 3회 비교의 95% 임계는 약 2.3점(6회 1.6, 10회 1.2) [기록 #195 S2]. 생성을 공유한 같은 세션 비교에서는 회차 SD 0.74로 5회 임계 0.9점까지 내려갔다(4-8).

## 6. 배운 것

1. **주 호출 한 번이 판단과 답을 다 하는 구조에서는 프롬프트를 고쳐도 경계만 옮겨 간다.** 점수가 움직인 것은 모두 판단을 따로 뗀 짧은 호출(E·T·classify)이나 결정적 덮기다.
2. **짧은 판단 호출은 출력 칸이 적고 근거를 먼저 옮기게 할 때 가장 좋았다**(E v0의 quote 칸, T 이름표 하나). 칸·갈래를 늘리거나 이유를 먼저 쓰게 하면 나빠졌다.
3. **공개 세트에 기댈수록 비공개 표본에서 이득이 준다.** C4(PC +1.9 → 제출 0), gc(제출 −2.5). 채택 전에 점검 세트와 실제 제출 2회 이상으로 확인한다.
4. **3회 비교는 2.3점 아래를 못 가린다.** 같은 생성에서 팔을 만드는 비교(조합 D)는 0.9점까지 가린다.
5. **호출 하나를 더하면 동시 64에서 게이트 대기 수 초가 붙는다.** 병렬로 셋을 보내는 구조(H)는 런박스에서 무너졌다. 마감(E 9초)을 두면 실제 채점은 통과했다.
6. **영어 질문은 검색·E가 한국어라 늘 '없음'이다.** 규칙으로 abstain만 막는다.
